# 例文に出てよい語（[Docs/06_features/wordbooks.md] §3.2）。
#
# 例文は「その語のレベルで読める語彙だけで構成する」ので、ビルドツールは
# 例文の語が「単語帳の見出し語（＋機械で広げた活用形）」に収まっているかを見る。
# ここには、その機械的な展開では拾えないものだけを置く。
#
#   - 不規則な活用形（went / bought / children）
#   - 例文に使う固有名詞（人名・地名・言語名）
#   - 綴りが変わる派生形（happiness / really）
#
# ここに語を足すのは「見出し語に入れない」と決めたときだけにする。
# 単語帳に入れるべき語を、警告を消す目的でここに逃がさない。
