英単語の単語帳を作ってください。
アプリに取り込める形式（下の仕様）の JSON だけを出力してください。説明文は不要です。

【テーマ】{{theme}}
【語数】{{count}}語（1回につき最大50語）
【レベル】{{level}}

【単語の選び方】
- そのテーマで実際によく使われる語を選ぶ。珍しい語で数を埋めない
- 同じ綴りで品詞が違う語は、別の項目として分ける
- 訳は、その品詞で最もよく使う語義から最大3つを「；」で区切る
- 例文はその語のレベルで読める語彙だけを使い、10語以内にする
- 例文を書いたら、和訳も必ず付ける
- 発音記号（IPA・米音）は自信がある語だけに書く。自信が無ければ書かない

【出力の形式】
{
  "encelloWordbook": "1",
  "name": "単語帳の名前（40文字以内）",
  "emoji": "絵文字1文字",
  "note": "説明（200文字以内・省略可）",
  "words": [
    {
      "headword": "英単語（英字・スペース・ハイフン・アポストロフィのみ）",
      "partOfSpeech": "noun / verb / adjective / adverb / preposition / conjunction / pronoun / interjection / phrase / unknown のいずれか",
      "phonetic": "発音記号（省略可）",
      "meaning": "日本語訳（200文字以内・必須）",
      "exampleEn": "英語の例文（省略可）",
      "exampleJa": "例文の和訳（exampleEn を書いたら必須）",
      "level": 1〜5の数字（省略時は1）
    }
  ]
}
