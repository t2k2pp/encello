直前のやりとりで挙げてもらった英単語を、アプリに取り込める形式（下の仕様）の JSON にしてください。
JSON だけを出力してください。説明文は不要です。

【変換のときの注意】
- 語を増やしたり減らしたりしない。挙げてもらった語だけを入れる
- 1回の出力が長いと途中で切れるため、50語を超える場合は50語ずつに分けて出力する
- 訳が無い語には、その品詞で最もよく使う語義を1つ書く
- 例文を書いたら、和訳も必ず付ける
- 発音記号（IPA・米音）は自信がある語だけに書く。自信が無ければ書かない

【出力の形式】
{
  "encelloWordbook": "1",
  "name": "単語帳の名前（40文字以内）",
  "emoji": "絵文字1文字",
  "note": "説明（200文字以内・省略可）",
  "words": [
    {
      "headword": "英単語（英字・スペース・ハイフン・アポストロフィのみ）",
      "partOfSpeech": "noun / verb / adjective / adverb / preposition / conjunction / pronoun / interjection / phrase / unknown のいずれか",
      "phonetic": "発音記号（省略可）",
      "meaning": "日本語訳（200文字以内・必須）",
      "exampleEn": "英語の例文（省略可）",
      "exampleJa": "例文の和訳（exampleEn を書いたら必須）",
      "level": 1〜5の数字（省略時は1）
    }
  ]
}
