# encello（エンチェロ）

英単語を **綴れるようになる** ための学習アプリです。

眺めて覚えるだけでは、いざ書こうとしたときに手が止まります。encello は
日本語の意味や発音から英単語の綴りを自分で入力させ、忘れかけた頃にもう一度出題します。

## 8つの学習モード

| モード | やること |
|---|---|
| ✏️ スペル | 日本語の意味を見て、英単語の綴りを入力します |
| 🎧 リスニング | 発音を聞いて、英単語の綴りを入力します |
| 🃏 フラッシュカード | 単語を次々に表示し、何枚か見たあとに「覚えているか」を4択かスペルで確かめます。送り方は 無音で自動送り／英語を読み上げて送り／日本語を読み上げて送り の3種類 |
| 🎯 4択クイズ | 4つの選択肢から正しい意味（または単語）を選びます |
| ⚡ スピード | 制限時間つきの4択を50問続けて。正解率ではなく「反応の速さ」を伸ばします |
| 🧩 語のつくり | 接頭辞・語根・接尾辞を覚えて、初めて見る単語の意味を推測します |
| 🔤 語形変化 | decide → decision のように、品詞を変えた形を綴ります |
| 🔀 取り違え | 自分がよく混同している2語を並べて、違いを身につけます |

## 特長

- **予測変換が出ないキーボード**
  スマホの標準キーボードは数文字打つと答えを候補に出してしまいます。
  encello はアプリの中に英字キーボードを持っているので、最後まで自分で綴ることになります。

- **語彙力を数で確かめられます**
  3分ほどのテストで、いまの推定語彙数と「中学・高校・英検の各レベルをどこまで知っているか」が分かります。
  次に取り組むとよい単語帳もそのまま提案します。ときどき測り直せば、増えた語数が目に見えます。

- **1語が10語を連れてきます**
  `port`（運ぶ）を覚えると import / export / transport / portable / support がつながります。
  単語の成り立ちと派生語をまとめて扱うので、覚える語が増えるほど推測が効くようになります。

- **間違え方は人それぞれ**
  解答の記録から、あなたが実際に取り違えている語の組を見つけ出して練習問題にします。
  よくある間違いリストではなく、あなたの間違いです。

- **忘れる頃にもう一度**
  正解・不正解と手ごたえに応じて、次に出題する日を1日後・6日後…と自動で伸ばします。
  覚えた単語は間隔が空き、あやふやな単語は繰り返し出てきます。

- **続けたくなる仕組み**
  1日の目標問題数、連続学習日数、経験値、実績バッジ。決まった時刻のお知らせもあります。

- **家族で1台を使えます**
  学習者を分けて登録できます。単語帳は共有しつつ、学習の記録・目標・画面の色は一人ひとり別々です。
  兄弟でレベルが違っても、それぞれの進み具合で学習できます。

- **出会った単語をその場で登録**
  教科書や動画で見つけた単語を、単語だけ登録しておいて後から訳を書けます。
  ほかのアプリから共有して登録することもできます。

- **音声は録音と合成の両方**
  音声ファイル（音声パック）を入れるとその発音で、入れていない単語は端末の音声合成で読み上げます。
  どちらを優先するかは設定で選べます。

- **単語帳を選べる**
  中学英単語・高校英単語・英検・TOEIC の単語帳を収録しています。
  自分で単語帳を作ったり、CSV から取り込むこともできます。

- **通信なしで使えます**
  単語も学習記録もすべて端末の中に保存されます。読み上げも端末の音声機能を使うため、
  電波の入らない場所でも学習できます。広告もアカウント登録もありません。
  詳しくは 設定 > 情報 > プライバシーポリシー（[PRIVACY_POLICY.md](PRIVACY_POLICY.md)）をご覧ください。

## 対応端末

- Android 8.0 以上
- iPhone / iPad（iOS 13 以上）

## バックアップ

設定 > データ から、単語帳と学習記録をファイルに書き出せます。
機種変更のときは、書き出したファイルを新しい端末で読み込むと学習の続きから始められます。
学習者が複数いる場合は、全員分がまとめて書き出されます。
