# 01. 要件（Requirements）

FR = 機能要件 / NFR = 非機能要件。各項目は [09_roadmap.md] のマイルストーンに割り当てる。

## 1. 単語・単語帳（FR-01〜FR-09）

| ID | 要件 |
|---|---|
| FR-01 | 単語は 見出し語・品詞・発音記号・日本語訳・英語例文・例文和訳・レベル を持つ |
| FR-02 | 単語帳（例: 中学英単語 / 英検2級）に単語を所属させる。1つの単語は複数の単語帳に属せる |
| FR-03 | プリセット単語帳を同梱し、初回起動時にDBへ投入する（[06_features/wordbooks.md]） |
| FR-04 | 学習に使う単語帳を複数選択できる。選択は学習者ごとに永続化する |
| FR-05 | ユーザーが単語を追加・編集・削除できる。プリセット単語も編集でき、編集済みであることを表示する |
| FR-06 | プリセット単語の編集は「元に戻す」で初期値へ復帰できる |
| FR-07 | 単語帳を CSV / JSON でインポートできる。列の対応をインポート前に確認する |
| FR-08 | 単語帳ごとに絵文字と識別色を設定できる |
| FR-09 | 単語を「除外」に指定でき、除外語は出題されない |

## 2. 学習モード（FR-10〜FR-29）

### 2.1 共通（FR-10〜FR-14）

| ID | 要件 |
|---|---|
| FR-10 | セッションの問題数を選べる（10 / 20 / 50 / 期限到来分すべて）。既定20 |
| FR-11 | 出題は「期限到来の復習」を優先し、不足分を新規語で埋める（[06_features/srs_scheduler.md]） |
| FR-12 | 出題順はセッションごとにシャッフルする。同じ順序が続かないこと |
| FR-13 | セッション途中で中断でき、中断時点までの解答は保存される |
| FR-14 | セッション終了時に 正解数 / 所要時間 / 獲得XP / 間違えた語の一覧 を表示し、間違えた語だけを再挑戦できる |

### 2.2 スペルモード（FR-15〜FR-20）

| ID | 要件 |
|---|---|
| FR-15 | 日本語訳・品詞・文字数（`_ _ _ _ _`）を提示し、英単語の綴りを入力させる |
| FR-16 | 入力は**アプリ内英字キーボード**で行う。OS の IME・予測変換・オートコレクトを一切表示しない |
| FR-17 | キーボードは QWERTY / ABC（アルファベット順）を設定で切り替えられる |
| FR-18 | ヒントボタンで未入力の先頭1文字を開示できる。ヒント使用は記録し、XP を減じる |
| FR-19 | 完全一致（大小・前後空白を無視）のみ正解。1文字違いは「惜しい」と表示するが不正解として扱う |
| FR-20 | 正解時は英単語を自動で読み上げ、例文を表示する |

### 2.3 リスニング・スペルモード（FR-21〜FR-23）

| ID | 要件 |
|---|---|
| FR-21 | 日本語訳を伏せた状態で英単語を読み上げ、綴りを入力させる |
| FR-22 | 再生ボタンで何度でも聞き直せる。再生回数を記録する |
| FR-23 | 読み上げ音声が利用できない端末ではこのモードを**選択肢ごと非表示**にする |

### 2.4 フラッシュカードモード（FR-24〜FR-26）

| ID | 要件 |
|---|---|
| FR-24 | 3つの送り方を選べる: ① 無音・固定秒で自動送り（上=日本語 / 下=英語）② 英語を読み上げ、再生終了で送り（上=英語 / 下=日本語）③ 日本語を読み上げ、再生終了で送り（上=日本語 / 下=英語） |
| FR-25 | ①の表示秒数を設定できる（2 / 3 / 5 / 8秒）。一時停止・戻る・進むを操作できる |
| FR-26 | カード表示中に「覚えた / あやしい」を押すと学習状態へ反映する（押さなければ状態は変えない） |

### 2.5 4択クイズモード（FR-27〜FR-29）

| ID | 要件 |
|---|---|
| FR-27 | 出題方向を EN→JA / JA→EN / ランダム から選べる |
| FR-28 | 誤答の選択肢は、同じ単語帳・同じ品詞の語を優先して選ぶ |
| FR-29 | 選択肢が4つ揃わない単語帳ではこのモードを選択肢ごと非表示にする |

## 3. 間隔反復（FR-30〜FR-34）

| ID | 要件 |
|---|---|
| FR-30 | SM-2 で次回出題日を算出する。正誤・自己評価・所要時間から grade を決める |
| FR-31 | 誤答した語は当日中に再出題する（同一セッション内の末尾へ戻す） |
| FR-32 | 習熟度（未学習 / 学習中 / 定着 / マスター）を学習状態から導出し、一覧・詳細に表示する |
| FR-33 | ホームに「今日の復習 N語」を表示し、1タップで開始できる |
| FR-34 | 正解率が低い語を「苦手」として抽出し、苦手だけの集中復習を開始できる |

## 4. 辞書（FR-35〜FR-39）

| ID | 要件 |
|---|---|
| FR-35 | 英語・日本語のどちらでも検索できる（両方を横断検索する） |
| FR-36 | 一覧は [STYLE_GUIDE §3] の型（検索・フィルタ2つ・ソート・リスト/グリッド切替）に従う |
| FR-37 | フィルタは「単語帳」「習熟度」。ソートは 見出し語 / 習熟度 / 最終学習日 |
| FR-38 | 単語詳細に 見出し語・発音記号・品詞・訳・例文（英日）・学習状態・履歴グラフ を表示する |
| FR-39 | 詳細から英語・日本語それぞれを読み上げられる |

## 5. 継続の仕組み・統計（FR-40〜FR-46）

| ID | 要件 |
|---|---|
| FR-40 | デイリー目標（問題数）を学習者ごとに設定できる。既定20、選択肢 10/20/30/50/100 |
| FR-41 | 目標達成でその日を達成扱いにし、連続達成日数（ストリーク）を数える |
| FR-42 | XP を付与する（正解 +10、ヒント使用は減額、モード別係数）。累計XPからレベルを算出する |
| FR-43 | 実績バッジを解除し、一覧できる |
| FR-44 | 統計に 習熟度の内訳ドーナツ・直近30日の学習量棒グラフ・正解率推移 を表示する |
| FR-45 | 統計に 苦手単語トップ20 を表示し、そこから集中復習へ入れる |
| FR-46 | 日付の切り替わりは端末ローカル時刻の 04:00 とする |

## 6. 音声（FR-47〜FR-50）

| ID | 要件 |
|---|---|
| FR-47 | 端末の TTS で英語・日本語を読み上げる |
| FR-48 | 読み上げ速度・ピッチ・音声（voice）を学習者ごとに設定でき、設定画面で試聴できる |
| FR-49 | 英語は米/英を選べる（端末に該当 voice がある場合のみ選択肢に出す） |
| FR-50 | 音声ファイルも合成音声も使えない語は、読み上げ操作を非表示にし、理由を1行で示す |

## 7. データ管理・設定（FR-51〜FR-57）

| ID | 要件 |
|---|---|
| FR-51 | 全データ（学習者・単語帳・単語・学習状態・履歴・設定）を JSON でエクスポート／インポートできる |
| FR-52 | 単語帳単位で CSV エクスポートできる |
| FR-53 | インポートは「追加」「置換」を選べる。置換は二段確認を要する |
| FR-54 | 設定は 表示 / 学習 / マスタ / データ / 情報 の5タブに分ける（[STYLE_GUIDE §5]） |
| FR-55 | テーマ配色を6色から選べる（既定ピンク）。文字サイズ・余白も選べる。いずれも学習者ごと |
| FR-56 | サンプルデータの投入・削除ができる |
| FR-57 | 学習状態のみをリセットできる（単語は残す）。二段確認を要する |

## 8. 学習プロファイル（FR-58〜FR-64）

[06_features/profiles.md]

| ID | 要件 |
|---|---|
| FR-58 | 1台の端末に複数の学習者を登録できる。単語は共有し、学習の記録は学習者ごとに分ける |
| FR-59 | 学習者は 名前・絵文字・識別色 を持つ。学習設定と表示設定も学習者ごとに持つ |

| FR-62 | 学習者を追加・編集・削除できる。最後の1人は削除できない |
| FR-63 | 学習者の削除は、消える記録の件数を明記して確認する。削除前にエクスポートを促す |
| FR-64 | ホーム・統計・実績・ストリークは、現在の学習者のデータだけを対象にする |

## 10. 語のつくり（FR-71〜FR-75）

[06_features/word_parts.md]

| ID | 要件 |
|---|---|

## 12. 取り違えドリル（FR-80〜FR-83）

[06_features/confusion_drill.md]

| ID | 要件 |
|---|---|
| FR-80 | 解答履歴から、その学習者が実際に取り違えている語の組を検出する |
| FR-81 | 組は2語を並べて出題する。解答後に両方の語の訳と品詞を示す |
| FR-82 | 不正解のときは両方の語の学習状態を下げる |
| FR-83 | 同じ組で5回連続正解したら解消済みとして出題対象から外す。再び誤答したら復活させる |

## 13. スピードモード（FR-84〜FR-87）

## 16. 発音の音源と音声パック（FR-98〜FR-104）

[06_features/pronunciation.md]

| ID | 要件 |
|---|---|
| FR-98 | 単語の発音は「音声ファイル」と「合成音声」の2つの音源から鳴らす。音声ファイルが無い語は合成音声で読む |
| FR-99 | 両方ある語をどちらで鳴らすかを設定で選べる（音声ファイル優先 / 合成音声優先 / 音声ファイルのみ / 合成音声のみ）。学習者ごとに持つ |
| FR-100 | いま何で鳴っているかを再生ボタンのバッジで示す。長押しで音源名を表示する |
| FR-101 | 音声パックを ZIP で取り込める。取り込み前に検証し、致命的な問題があれば1件も取り込まない |
| FR-102 | 音声パックを複数持てる。使用の ON/OFF と優先順位を設定できる。同じ語が複数にあれば優先順位の高い方を使う |
| FR-103 | 音声ファイルの再生に失敗したとき、合成音声に切り替えず失敗として扱う（「無い」と「壊れている」を区別する） |
| FR-104 | 例文は常に合成音声で読む。音声ファイルを持たせない |

## 17. AI に作ってもらった単語帳の取り込み（FR-105〜FR-112）

[06_features/ai_import.md]

| ID | 要件 |
|---|---|
| FR-105 | 生成AI に単語帳を作ってもらうための定型文を、アプリからコピーできる。テーマ・語数・レベルを差し込める |
| FR-106 | AI の出力を貼り付けて単語帳として取り込める。**アプリから AI を呼ばない**（通信しない） |
| FR-107 | 取込データは版フィールドを必須にする。未知の版は取り込まず、アプリの更新を促す |
| FR-108 | 貼り付けたテキストの前後にある説明文やコードフェンスを取り除いてから読む。構文の推測修復は行わない |
| FR-109 | 検証エラーは最初の1件で打ち切らず、行番号と理由を全件列挙する |
| FR-110 | 取り込む前にプレビュー（単語帳名・語数・先頭20語）と、**新しく増える語数**を示す。既存語は所属だけを足し、訳を上書きしない |
| FR-111 | 弾いた行があるときは「正しい語だけ取り込む」「やめる」を選ばせる。推測で補完しない |
| FR-112 | 取り込みに失敗したとき、エラー内容と元テキストを含む「AI に直してもらう文」をコピーできる |

## 非機能要件（NFR）

| ID | 要件 | 検証 |
|---|---|---|
| NFR-01 | 出題の切り替わり（解答→次の問題）は 100ms 以内。TTS の待ちで入力がブロックされない | 実機計測 |
| NFR-02 | 10,000語の単語帳でも辞書検索・ソートが UI をブロックしない | 大量データのウィジェットテスト |
| NFR-03 | 解答は1問ごとに即時 DB へ書き込む。アプリが強制終了しても直前までの学習が残る | 統合テスト |
| NFR-04 | TTS を除く全機能がネットワーク接続なしで動作する。フォントは同梱し、起動時に取得しない | 機内モードでの起動確認 |
| NFR-05 | すべてのテキストが 幅 320dp × textScaler 1.6 でも溢れない | `test/widget/overflow_matrix_test.dart` |
| NFR-06 | 最小タップ領域 44×44。アイコンボタンには tooltip を付ける | ウィジェットテスト |
| NFR-07 | `domain/` の純粋ロジックはユニットテストで分岐を網羅する | `flutter test` |
| NFR-08 | 起動から最初のフレーム描画までにプラグイン初期化を待たない。初期化は10秒でタイムアウトし失敗を表示する | [02_architecture.md] §4 |
| NFR-09 | DB マイグレーションは `drift_dev` のスキーマテストで各版を検証する | [07_testing_strategy.md] |
| NFR-10 | 学習中の画面はスリープさせない（フラッシュカードの自動送り中を含む） | 実機確認 |
| NFR-11 | 学習に関わるクエリは必ず `profileId` を条件に含める。リポジトリの引数を必須にする | コードレビュー＋ユニットテスト |
| NFR-12 | スピードモードの制限時間判定は描画フレームに依存しない（`Stopwatch` で計測する） | ユニットテスト |
