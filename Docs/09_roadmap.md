# 09. ロードマップ（Roadmap）

各マイルストーンの終わりに `flutter analyze` と `flutter test` が通り、実機で動く状態にする。

## M1: 基盤

- `flutter create` とディレクトリ構成（[02_architecture.md] §5）
- `pubspec.yaml` の依存追加、Noto Sans JP の同梱
- デザイントークン（`AppColors` 6配色 / `AppText` / `AppSpacing`）と共通部品
  （`SoftCard` / `EmptyState` / `CenteredContent` / `confirmDestructive`）の移植
- `BootstrapGate`（起動ゲート・10秒タイムアウト・再試行）
- `RootShell`（4タブ + FAB）と空の各画面

**完了条件**: 4タブが切り替わり、テーマ配色を変えると全画面に反映される。

## M2: 単語帳とデータ

- 辞書一覧（SCR-08）と単語詳細（SCR-09）

**完了条件**: 辞書で検索・絞り込み・並べ替えができ、単語を編集できる。

## M3: スペルモード（このアプリの核）

- `Sm2Scheduler` / `GradeResolver` / `StudyQueueBuilder`（ユニットテストを先に固める）
- `StudySessionController` と `AnswerSubmissionService`（1問1トランザクション）
- モード選択シート（SCR-02）と結果画面（SCR-07）

**完了条件**: スペルで20問のセッションを完走でき、翌日に復習として出てくる。
学習画面に `EditableText` が1つも無い。

## M4: 残り3モードと読み上げ

| 物語（Cloze）モード | 英文ストーリーの穴埋め。文脈の中で語を覚える。本文コンテンツの整備が別途必要（下記） |

### 物語モードの前提

英文ストーリーを本文として同梱する場合、**原作の著作権が切れているものに限る**。
グリム／アンデルセン／イソップ／日本の昔話／宮沢賢治・新美南吉・芥川龍之介などは
保護期間が満了しているが、20世紀以降の作品（および現行の翻訳・翻案）はそのまま扱えない。
英文は既存の翻訳・再話を写さず、原典から新たに書き起こす必要がある。
この整備コストが本体開発と同規模になるため、v1 から外している（[00_overview.md]）。

例文の穴埋め（上表の2つ目）は同じ「文脈で覚える」体験を、
すでに持っている例文だけで提供できる。物語モードより先に検討する。
