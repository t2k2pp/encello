# 語彙力測定とレベル判定（Vocabulary Size Test）

対応要件: FR-65〜FR-70
実装: `domain/usecases/vocab_size_estimator.dart`, `ui/screens/vocab_test_screen.dart`,
`assets/pseudowords.json`

## 1. 狙い

「単語力が上がっている」を数値で見せる。そして、**その人のレベルから学習を始められるようにする**。

すでに知っている語を延々と解かされるのが、語彙学習で最も意欲を削ぐ。
逆に、難しすぎる単語帳から始めても続かない。測ってから始める。

## 2. 方式：Yes/No テスト＋擬似語による当てずっぽう補正

4択や記述で測ると1問あたり10〜20秒かかり、精度に必要な問題数を出せない。
Yes/No 方式（「意味が言える？」に はい/いいえ で答える）なら1問2〜3秒で済む。

代わりに「知ったかぶり」が入り込むので、**実在しない語（擬似語）を混ぜて補正する**。

```
出題 50問 = 実在語 40問（帯ごとに配分）+ 擬似語 10問
```

- 画面は語を1つ大きく出し、下に「わかる」「わからない」の2ボタンだけ。
- 擬似語であることは最後まで伏せる。結果画面で「実在しない語が10問混ざっていました」と明かす。
- 所要時間は約3分。

### 2.1 補正式

帯ごとに次を計算する。

```
h = その帯の実在語で「わかる」と答えた率
f = 擬似語で「わかる」と答えた率（テスト全体で1つ）
corrected = f < 1 ? clamp((h - f) / (1 - f), 0, 1) : 0
```

`f` が高い（擬似語にも「わかる」と答えた）人ほど、実在語の正答も割り引かれる。

## 3. 帯の取り方

一般的な頻度帯（1000語ごと）ではなく、**このアプリが持っている級帯**で測る。

| 帯 | 出題数 | 帯の語数（目安） |
|---|---|---|
| 中学英単語 | 8 | 1,600 |
| 高校 基礎 | 8 | 1,200 |
| 高校 応用 | 8 | 1,300 |
| 英検準2級 | 8 | 900 |
| 英検2級 | 8 | 1,100 |

推定語彙数 = Σ（帯の語数 × その帯の `corrected`）

級帯で測るのは、結果がそのまま行動に繋がるため。
「推定 3,200語」より **「準2級の語彙を41%知っています。到達まであと約1,540語」** の方が、
次に何をすればいいかが分かる。

- 出題する語は帯からランダムに選ぶ。同じ帯の中では均等に散らす。
- 直近の測定で出した語は、次回の測定では優先度を下げる（同じ語ばかり出ないように）。
- **測定の結果は `word_reviews` に一切書かない**。測定は学習ではない。
  「わかる」と答えただけの語を既習にすると、学習状態が実態から離れる。

## 4. 擬似語

`assets/pseudowords.json` に120語を同梱し、毎回そこから10語を選ぶ。

- 英語として発音・綴りが自然に見えるものにする（`blample` `cansive` `dorpent` のように、
  英語の音素配列と接尾辞の形に従う）。明らかに英語らしくない綴りは、
  それだけで「わからない」と答えられてしまい補正にならない。
- **実在語でないことを作成時に確認する**。同梱の全単語帳、および英語の一般語彙リストと突き合わせる。
  確認の取れていない語はリストに入れない。
- 擬似語には訳も例文も持たせない。`words` テーブルには入れず、アセットのまま扱う。

```
  中学英単語     ████████░░  92%   （約1,470語）
  高校 基礎      ██████░░░░  58%   （約700語）
  高校 応用      ███░░░░░░░  31%   （約400語）

  次に取り組むとよい単語帳: 高校 基礎
  [ この単語帳を学習対象にする ]

  ※ 実在しない語が10問混ざっていました。うち2問に「わかる」と答えています。
```

### 5.1 推奨単語帳の決め方

`corrected` が **0.9 未満で最も易しい帯**を推奨する。

- 「9割方知っている帯」は取り組む価値が薄い。
- 難しい帯へ飛ばすと、未知語だらけで続かない。
- 該当が無い（全帯が0.9以上）場合は、最上位の帯を推奨し「かなり仕上がっています」と添える。

推奨をそのまま学習対象に設定するボタンを置く。押さなければ何も変えない。

## 6. 測定のタイミング

| 契機 | 挙動 |
|---|---|
| プロファイル新規作成の直後 | 案内する。断ることもできる（後から設定 > 学習でいつでも測れる） |
| 前回の測定から30日経過 | ホームに「語彙力を測り直しませんか」のカードを出す。閉じられる |
| 手動 | 設定 > 学習「語彙力を測る」／統計画面の語彙力カード |

- 測定間隔が短すぎると差が誤差に埋もれるので、**7日以内の再測定は警告を出す**
  （実行はできる。「前回から6日です。差が誤差の範囲になることがあります」）。

## 7. 記録

`vocab_size_tests` テーブル（[03_data_model.md] §2.10）に1回1行。

| 列 | 説明 |
|---|---|
| `id` / `profileId` / `takenAt` | |
| `estimatedSize` | 推定語彙数 |
| `falseAlarmRate` | 擬似語に「わかる」と答えた率 |
| `bandResults` | 帯ごとの `corrected` と出題数を JSON で |
| `askedWordIds` | 出題した実在語の id（次回の重複回避用）を JSON で |

統計画面に「語彙力の推移」カードを置き、測定ごとの推定語彙数を折れ線で描く（[stats.md] §10）。

## 8. 精度についての表示

推定値は誤差を含む。数値を断定的に見せない。

- 結果画面と統計カードに caption で「40問からの推定値です。±10%程度の幅があります」と添える。
- 前回差が推定誤差より小さい場合（絶対値が推定値の10%未満）は、
  「+320語」ではなく **「前回とほぼ同じです」** と表示する。
  誤差を成長として見せない。

## 9. テスト観点

- `f = 0` のとき `corrected = h` になる。
- `f = 0.5`、`h = 0.75` のとき `corrected = 0.5` になる。
- `f = 1`（擬似語全部に「わかる」）のとき全帯が 0 になる。
- `h < f` のとき負にならず 0 に丸められる。
- 推定語彙数が Σ(帯語数 × corrected) と一致する。
- 推奨単語帳が「0.9 未満で最も易しい帯」になる。全帯 0.9 以上なら最上位。
- 測定後に `word_reviews` が1行も増減しない。
- 前回差が推定値の10%未満のとき「ほぼ同じ」と表示される。
- 直近の測定で出した語が、次回の出題で優先度を下げられる。
- 擬似語リストに同梱単語帳の見出し語が1つも含まれない（アセットの検証テスト）。
