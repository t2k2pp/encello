# スピードモード（Fluency Drill）

対応要件: FR-84〜FR-87
実装: `ui/screens/speed_study_screen.dart`, `providers/reaction_time_stats.dart`

## 1. 狙い

SRS は「正しく思い出せる」を鍛えるが、読解に必要なのは
**見た瞬間に意味が出てくる速さ**（自動化）で、これは別の能力になる。

1語に2秒かかると、英文を読む速度がそこで律速される。
正解率が100%でも遅ければ、まだ「使える」語彙になっていない。

このモードが記録するのは正解率ではなく **平均反応時間**。

## 2. 出題

- 形式は4択（[quiz_mode.md] と同じ描画・同じ誤答選択肢の選び方）。
- **制限時間つき**。既定3秒、設定で 2 / 3 / 5 秒（`profiles.speedLimitMs`）。
- 残り時間を選択肢の上に細いバーで描く。数字のカウントダウンは出さない（急かしすぎる）。
- 50問連続。途中にフィードバック帯を挟まず、**正誤の表示は0.4秒の色フラッシュだけ**で次へ進む。
  1問ずつ止まると流暢性の訓練にならない。
- 間違えた語と時間切れの語は、**最後にまとめて**結果画面で振り返る。

## 3. 出題対象

**すでに学習した語（`masteryLevel >= 1`）に限る**。

未学習の語を制限時間つきで出しても、考える時間が無いだけで何も身に付かない。
このモードは「知っている語を速くする」ためのもので、新しい語を覚えるためのものではない。

対象が20語未満の場合は、モード選択にスピードモードを出さない。

## 4. 学習状態への反映

| 結果 | grade | 理由 |
|---|---|---|
| 時間内に正解 | 4 | 通常どおり間隔を伸ばす |
| **時間切れ** | 更新しない | 「知らない」ではなく「遅い」。間隔の判断材料にしない |
| 時間内に誤答 | 1 | 通常どおり |

時間切れを誤答扱いにすると、知っている語の間隔が不当に縮み、
復習キューが「知っているが遅い語」で埋まってしまう。速さの情報は反応時間で別に持つ。

`learning_logs` には時間切れも記録する（`mode = speed`, `isCorrect = false`,
`grade = -1`（学習状態を更新しなかったことを表す番兵）, `elapsedMs = 制限時間`）。
反応時間の統計はログから作るので、記録自体は残す必要がある。

## 5. 結果画面

```
スピード結果

     平均 1.42 秒        ← 大書き
     前回 1.68 秒 から -0.26 秒

  時間内に正解  44 / 50
  時間切れ       4
  誤答           2

  ┌ 反応時間の分布 ────────────┐
  │  ▁▃▆█▇▅▃▂▁        │      │  ← ヒストグラム。縦線は制限時間
  └──────────────────────────┘

  遅かった語（2.5秒以上）  6語 >
  時間切れの語              4語 >
  間違えた語                2語 >
```

- 平均は**時間内に正解した問題だけ**で計算する。時間切れ（＝制限時間）を混ぜると、
  制限時間を変えたときに平均が動いてしまい、回どうしで比べられなくなる。
- 「遅かった語」から、その語だけの通常セッションへ入れる。

## 6. 統計での見せ方

統計画面に「反応の速さ」カードを置く。

- 直近30日の平均反応時間の折れ線。制限時間を破線で重ねる。
- 実施が0回の日は点を打たず線を切る（[stats.md] §4 と同じ扱い）。
- 語ごとの反応時間は単語詳細にも出す（「平均 1.8秒（10回）」）。
  同じ習熟度でも速い語と遅い語があることが見える。

## 7. XP

正解の基本点10 × モード係数 **1.2**。

- 4択（×1.0）より高く、スペル（×1.5）より低い。
  制限時間ぶんの負荷はあるが、産出（綴る）ではないため。
- 時間切れは0。誤答も0。
- 「50問すべて時間内」で +50 のボーナス。

## 8. テスト観点

- 未学習語（`masteryLevel = 0`）が出題されない。
- 対象が19語のときモード選択にスピードモードが出ない。
- 時間切れで `word_reviews` が更新されない。
- 時間切れが `learning_logs` に `grade = -1` で記録される。
- 平均反応時間が「時間内に正解した問題」だけで計算される。
- 制限時間を3秒→5秒に変えても、過去回の平均が変化しない。
- 0.4秒のフラッシュ後に自動で次の問題へ進む（`FakeAsync` で検証）。
- 50問すべて時間内正解でボーナス XP が付く。
