# 辞書（Dictionary）

対応要件: FR-35〜FR-39, NFR-02
実装: `ui/screens/dictionary_screen.dart`, `ui/screens/word_detail_screen.dart`,
`providers/dictionary_listing.dart`

## 1. 一覧

[STYLE_GUIDE §3] の一覧画面の型をそのまま使う（[04_screens_and_flows.md] §4.7）。
本書は encello 固有の中身だけを定める。

### 1.1 検索（FR-35）

- 1つの検索欄で英語と日本語の**両方を横断**する。入力の文字種でモードを切り替えない。
  「apple」でも「りんご」でも同じ欄に打てば出る、が利用者の期待に合う。
- 対象列と一致方法:

| 列 | 一致 | 備考 |
|---|---|---|
| `headword` | 前方一致を先に、次に中間一致 | 前方一致の結果を上に並べる |
| `meaning` | 中間一致 | |
| `exampleEn` / `exampleJa` | 中間一致 | 「例文も検索する」が ON のときだけ（既定 OFF） |

- 検索文字列は小文字化・前後空白除去してから使う。
- 例文検索を既定 OFF にするのは、単語を引きたいときに例文ヒットが混ざると見つけにくいため。
- `meaning` の中間一致はインデックスが効かないが、1万語で全走査しても数ミリ秒で終わる
  （[03_data_model.md] §3）。FTS は導入しない。

### 1.2 フィルタ（プルダウン2つ）

| プルダウン | 選択肢 |
|---|---|
| 単語帳 | すべて / 学習対象のみ / マイ単語 / 各単語帳（登録語数の多い順） |
| 習熟度 | すべて / 未学習 / 学習中 / 定着 / マスター / 苦手 / 下書きのみ |

- 「苦手」は解答10回以上かつ正解率60%未満（[srs_scheduler.md] §6.2 と同じ定義）。
- 「下書きのみ」は訳が未入力のマイ単語（[my_words.md] §3）。
- 一覧に出るのは **共有の語 ＋ 自分のマイ単語**。他の学習者のマイ単語は出ない。
- 習熟度は現在の学習者のもの。学習者を切り替えると同じ語の表示が変わる。

### 1.3 ソート

| 項目 | 昇順の意味 |
|---|---|
| 見出し語（既定） | a → z |
| 習熟度 | 未学習 → マスター |
| 最終学習日 | 古い → 新しい。未学習は末尾に置く |

昇順/降順は `SegmentedButton` でトグルする。

### 1.4 表示

- `WordThumb` の「単語帳色」は、その語が属する単語帳のうち `sortOrder` が最小の1冊の
  `colorSeed` を使う。どの単語帳にも属さない語は `chipBg` の無彩色にする。
- リスト行 = `SoftCard`: `WordThumb`（見出し語の先頭1文字＋単語帳色＋習熟度リング）｜
  見出し語（15/w700, ellipsis）＋ caption（品詞・発音記号を `・` で結合）｜
  右カラム（`maxWidth: 110`）に和訳（`maxLines: 2`, ellipsis）と `MasteryBadge`。
- グリッドタイル = 中央に見出し語（`FittedBox`）、下に和訳（`maxLines: 2`）、右下に習熟度ドット。
- 行タップ = 単語詳細へ push。
- 空状態は「未登録」と「絞り込みゼロ件」で分ける（[STYLE_GUIDE §3.7]）。
  未登録側のアクションは「単語帳を選ぶ」（SCR-12 へ）。

### 1.5 大量データでの挙動（NFR-02）

- 一覧は `ListView.builder` / `GridView.builder` で遅延構築する。
- 絞り込みと並べ替えは **SQL 側で行う**。全件を Dart に読んでからフィルタしない。
- 検索欄の入力は 250ms のデバウンスをかけてからクエリを投げる。
- 件数キャプション（「1,842語 ・ 学習中 312語」）は `COUNT` クエリで別に取る。
  一覧の行を数えない。

## 2. 単語詳細（SCR-09）

[04_screens_and_flows.md] §4.8 のカード構成。追加の規則:

- 例文が無い語では例文カードごと出さない（空のカードを置かない）。
- 発音記号が無い語では 🔊 は出す（読み上げは `headword` を渡すため。[tts.md] §5）。
- 所属単語帳のチップは `Wrap` で折り返す。タップでその単語帳の中身（SCR-13）へ。
- 学習状態カードは、`word_reviews` の行が無い語では
  「まだ学習していません」＋「この語だけ復習」ボタンだけを出す。0 の羅列を並べない。
- 履歴のドット列は直近20回。20回未満はその数だけ描く。

### 2.1 「この語だけ復習」

その1語だけのセッションをスペルモードで開始する。
1問終わったら結果画面を挟まず、元の詳細画面へ戻り、学習状態カードが更新される。

### 2.2 編集・削除・除外

- 編集は `upsert_word_sheet`（[STYLE_GUIDE §4.2] の型）。
  `(headword, partOfSpeech)` を他の語と衝突する値に変えようとした場合は保存せず、
  「同じ見出し語と品詞の単語がすでにあります」と示す。
- 削除は `confirmDestructive`。学習状態と履歴も一緒に消えることを本文に明記する。
- 除外（FR-09）は削除ではない。出題から外すだけで、辞書には残り、学習状態も保持する。
  除外中の語は一覧で `ink3` の斜線バッジ「除外中」を付ける。

## 3. テスト観点

- 「apple」「りんご」のどちらでも同じ語がヒットする。
- 前方一致の結果が中間一致より上に並ぶ。
- 「例文も検索する」が OFF のとき、例文だけに含まれる語がヒットしない。
- 習熟度フィルタ「未学習」で `word_reviews` の行が無い語だけが出る。
- 最終学習日の昇順で未学習が末尾に来る。
- 1万語のフェイクデータで一覧の初回描画がフレーム落ちしない（`ListView.builder` の遅延構築）。
- 例文が無い語の詳細に例文カードが存在しない。
- 部品の紐付けが無い語の詳細に語のつくりカードが存在しない。
- 語族に自分しかいない語の詳細に語族カードが存在しない。
- 取り違えの組が無い語の詳細に取り違えカードが存在しない。
- 他の学習者のマイ単語が一覧に出ない。
- 学習者を切り替えると同じ語の習熟度バッジが変わる。
- `(headword, partOfSpeech)` の衝突する編集が保存されない。
- 除外した語と下書きがキュー生成に含まれず、辞書には残る。
