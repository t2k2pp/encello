# 4択クイズモード（Choice Mode）

対応要件: FR-27〜FR-29
実装: `ui/screens/choice_study_screen.dart`, `domain/usecases/choice_distractors.dart`

## 1. 出題方向

| 方向 | 問い | 選択肢 |
|---|---|---|
| `enToJa` | 英単語（＋発音記号）と読み上げボタン | 日本語訳 4つ |
| `jaToEn` | 日本語訳 | 英単語 4つ |
| ランダム（既定） | 問題ごとに上記のどちらかを選ぶ | |

`enToJa` で読み上げボタンを出すのは、音を確認する機会を増やすため。押しても grade には影響しない。

## 2. 誤答選択肢の選び方

`ChoiceDistractors.pick(correct, pool, random)` は純粋関数。次の優先順で3つ埋める。

1. 同じ単語帳・**同じ品詞**の語
2. 同じ単語帳の語（品詞不問）
3. 選択中の全単語帳の語

- 品詞を揃えるのは、選択肢を見ただけで答えが割れないようにするため。
  「りんご / 走る / 美しい / すばやく」では品詞から正解が特定できてしまう。
- `jaToEn` では、正解と**先頭文字が同じ語**を1つ以上入れるよう試みる（見た目で消せないようにする）。
  該当が無ければ通常の候補で埋める。
- 訳文が正解と完全一致する語は候補から除く（同義語で正解が2つになるのを防ぐ）。
- 4つ揃わない場合は**このモードを出さない**（FR-29）。ダミー文字列を作って埋めない。
  判定は「選択中の単語帳の語数が4未満」でモード選択の時点で行う。

## 3. 選択肢の配置

- 正解の位置は毎回ランダム。直前の問題と同じ位置に正解を置かない
  （位置の癖で当てられるのを防ぐ）。
- 選択肢は縦4行の `SoftCard`。高さは内容に応じて伸びる（固定しない）。
  長い訳文は `maxLines: 3` + ellipsis。

## 4. 判定とフィードバック

- タップした瞬間に確定する。取り消しはできない。
- 正解を `correct` の枠と ✓、誤答を選んだ場合はその選択肢を `wrong` の枠と ✕ で示し、
  同時に正解も緑で示す。
- 「次へ」でのみ進む。自動送りの設定は 4択には適用しない
  （どれが正解だったかを見る時間が必ず要る）。
- grade は正誤のみで決める（[srs_scheduler.md] §2）。正解でも 5 は出さない。

## 5. 記録

| テーブル | 内容 |
|---|---|
| `learning_logs` | mode=`choice`, direction, isCorrect, grade, answeredText=選んだ選択肢の文字列, elapsedMs |
| `word_reviews` / `daily_stats` / `study_sessions` | 他モードと同じ |

`answeredText` に選んだ選択肢を残すのは、後から「どの語と取り違えたか」を苦手分析に使えるようにするため。

## 6. テスト観点

- 誤答3つに正解と同じ語が混ざらない。
- 訳文が正解と同一の語が誤答に入らない。
- 同じ品詞の候補が3つ以上あるとき、誤答はすべて同じ品詞になる。
- 候補が4未満のプールでは `pick` が空を返し、モード選択にこのモードが出ない。
- 正解の位置が直前の問題と同じにならない。
- 正解でも grade が 4 を超えない。
