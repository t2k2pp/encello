# リスニング・スペルモード（Listening Mode）

対応要件: FR-21〜FR-23
実装: `ui/screens/listening_study_screen.dart`（スペルモードと画面部品を共有）

## 1. 位置づけ

スペルモードの提示部分だけを差し替えたモード。入力・判定・記録は
[spell_mode.md] とまったく同じ実装を使う（`SpellJudge` / `EnglishKeyboard` / `LetterTiles` / `VerdictBanner`）。
差分は本書の §2 と §3 だけ。

## 2. 出題

| 提示するもの | 提示しないもの |
|---|---|
| 英単語の読み上げ（自動で1回） | 日本語訳 |
| 再生ボタン（何度でも） | 英単語の綴り |
| 文字数（`_` の数） | 品詞・発音記号 |

- 出題が描画された直後に自動で1回読み上げる。
- **日本語訳を伏せる**のがこのモードの要点。音から綴りを起こす練習にする。
  訳を出すとスペルモードとの差が「音が鳴るかどうか」だけになる。
- 再生ボタンは大きく（直径72dp）、画面中央に置く。押した回数を `replayCount` に記録する。
- ヒントボタンはスペルモードと同じ（先頭1文字ずつ開示）。
  加えて「訳を見る」ボタンを置き、押すと日本語訳を表示する。訳を見た場合は grade の上限を 3 にする
  （音だけでは思い出せなかったため）。

## 3. 判定後

`VerdictBanner` に、正解の綴り・発音記号・**日本語訳**・例文を出す。
正解時は再度読み上げる（正しい音と綴りを結び付けるため）。

## 4. 音声が使えない端末での扱い

`PronunciationService.resolve()` が、対象単語帳のどの語についても英語で `null` を返す場合
（＝英語の音声ファイルも英語 voice も無い）:

- ホームのモードカード（[04_screens_and_flows.md] §4.1）から**リスニングのカードを非表示**にする。
- モード選択シートのモード一覧からも取り除く。
- 無効化してグレー表示にはしない（[STYLE_GUIDE §0-4]）。
- 設定 > 学習 の読み上げカードに、利用できない旨を1行で表示する（[tts.md] §4）。

セッション中に読み上げが失敗した場合は、セッションを中断して結果画面へ送る。
音が鳴らないまま綴りを問い続けない。中断は `study_sessions.finishedAt` を立てて確定させ、
そこまでの解答は保持する。

## 5. 記録

`learning_logs` に `mode = listening`, `direction = enToJa`（音＝英語が問い）で記録する。
`replayCount` に再生回数、`hintUsed` にヒント文字数を入れる。

## 6. テスト観点

- 出題描画時に `PronunciationService.speakWord` が英語で1回だけ呼ばれる。
- 再生ボタンを3回押すと `replayCount = 3` で記録される。
- 「訳を見る」を押した後に正解しても grade が 3 を超えない。
- 英語の音声ファイルも英語 voice も無いとき、ホームのモードカードとモード選択肢に
  リスニングが現れない。
- 英語 voice が無くても英語の音声パックがあればリスニングが選べる。
- `speakWord` が例外を投げたときにセッションが中断され、それまでの解答が残る。
