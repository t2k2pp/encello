# 統計（Statistics）

対応要件: FR-44, FR-45
実装: `ui/screens/stats_screen.dart`, `ui/screens/session_history_screen.dart`,
`ui/screens/achievements_screen.dart`, `data/repositories/stats_repository.dart`,
`providers/stats.dart`（Provider 定義）, `providers/stats_aggregates.dart`,
`providers/reaction_time_stats.dart`, `ui/widgets/donut_chart.dart`,
`ui/widgets/bar_chart.dart`（`BarChart` と `LineChart`）, `ui/widgets/streak_calendar.dart`,
`ui/widgets/band_progress_bar.dart`

## 1. カード構成（SCR-10）

すべてのカードは**現在の学習者**のデータだけを対象にする（[profiles.md] §7）。

| # | カード | データ源 | 集計範囲 |
|---|---|---|---|
| 1 | 語彙力 | `vocab_size_tests` | 測定時の級帯 |
| 2 | 習熟度の内訳 | `words` × `word_reviews` | **選択中の単語帳** |
| 3 | 直近30日の学習量 | `daily_stats` | 全体 |
| 4 | 正解率の推移 | `daily_stats` | 全体 |
| 5 | 反応の速さ | `learning_logs`（`mode = speed`） | 全体 |
| 6 | ストリーク | `daily_stats` | 全体 |
| 7 | 苦手単語トップ20 | `word_reviews` | 選択中の単語帳 |
| 8 | よく取り違える組 | `learning_logs` × `resolved_confusions` | 全体 |
| 9 | 学習履歴 | `study_sessions` | 全体 |

集計範囲が違う理由は [gamification.md] §5 のとおり。
カード2と7のヘッダに caption で「学習対象の単語帳のみ」と明示する。

## 2. 語彙力

- 最新の `vocab_size_tests` から、推定語彙数（大書き）と級帯ごとの `BandProgressBar`。
- 2回目以降は前回差を添える。差が推定値の10%未満なら「前回とほぼ同じです」
  （[vocab_size_test.md] §8）。
- 測定が2回以上あれば、推定語彙数の推移を折れ線で描く。横軸は測定日（等間隔ではなく実日付）。
- 「測り直す」ボタン（SCR-18 へ）。前回から7日以内なら押す前に警告を出す。
- 一度も測っていなければ `EmptyState`「まだ測定していません」＋「語彙力を測る」。

## 3. 習熟度の内訳

- `DonutChart`（pricello から移植）。セグメント色は [05_design_system.md] §1.3。
- 凡例は色ドット＋名称＋語数＋割合。
- 中央に「学習した語 / 全体」（例 `1,204 / 3,800`）。
- **語単位 / 語族単位**を `SegmentedButton` で切り替える（[word_families.md] §6）。
  語族単位は「手つかず / 一部 / 全部」の3分割になる。
  語族に属する語が1つも無い状態では切替を出さない。
- 未学習が 100% のとき（まだ何も学習していない）は、円ではなく `EmptyState`
  「まだ学習の記録がありません」＋「学習をはじめる」ボタンにする。

## 4. 直近30日の学習量

- `BarChart`。横軸は学習日（04:00 区切り）、縦軸は `answeredCount`。
- デイリー目標を破線で重ねる。目標を達成した日のバーは `accent`、未達は `chipBg`。
- 学習していない日も**バー0で描く**（日付を詰めない）。空白があることが情報になる。
- 30日分の `daily_stats` を1クエリで取り、Dart 側で欠損日を 0 で埋める。

## 5. 正解率の推移

- 折れ線（`BarChart` と同じ `CustomPainter` の作法）。
- **解答が 0 の日は点を打たず、線を切る**。0% として繋ぐと「その日は全部間違えた」に見えるため。
- 縦軸は 0〜100% 固定。データに合わせて伸縮させない（日ごとの比較が崩れる）。

## 6. 反応の速さ

- 直近30日の平均反応時間の折れ線。制限時間を破線で重ねる（[speed_mode.md] §6）。
- 平均は**時間内に正解した問題だけ**で取る。時間切れを混ぜると、
  制限時間を変えたときに平均が動いて回どうしを比べられなくなる。
- スピードモードを実施していない日は点を打たず、線を切る。
- 一度もスピードモードをやっていなければカードごと出さない。

## 7. ストリーク

- 現在の連続日数（大書き）・最長記録・今月のカレンダー（`StreakCalendar`）。
- カレンダーは達成日を `accent`、学習したが未達の日を `accentSoft`、
  学習していない日を無地で塗る。3段階を凡例で示す。
- 月の切り替え（◀ ▶）で過去の月を見られる。

## 8. 苦手単語トップ20

- 条件: 解答10回以上かつ正解率60%未満。並びは正解率の昇順、同率なら解答数の降順。
- 行 = 見出し語 ＋ 和訳 ＋ 「12回中4正解（33%）」＋ `MasteryBadge`。行タップで単語詳細。
- カード下部に `FilledButton`「苦手だけ復習（N語）」。押すとモード選択シートが
  「苦手のみ」を選んだ状態で開く。
- 条件を満たす語が無いときは、カードの中に「苦手な単語はありません」＋条件の説明を1行出す。
  条件を緩めて無理に20語埋めない。

## 9. よく取り違える組

- `ConfusionPairFinder` の結果を誤答回数の降順で最大10組（[confusion_drill.md] §2）。
- 行 = `affect ⇄ effect` ＋ caption「6回取り違えています」。行タップで両語の詳細を並べたシート。
- カード下部に `FilledButton`「まとめて練習（N組）」。押すと取り違えドリルが始まる。
- 下部に caption で「解消した組 4件」。減っていることも成果として見せる。
- 組が0件のときはカードごと出さない。「まだデータが足りません」を置かない。

## 10. 学習履歴（SCR-15）

- `study_sessions` を `startedAt` の降順で一覧する（`ListView.builder`、ページング50件）。
- 行 = 日時 ｜ モードの絵文字と名称 ｜ 「16/20 正解 ・ 4分32秒 ・ +180 XP」。
- 中断したセッション（`finishedAt` が null）は「中断」バッジを付ける。消さない。
- 行タップでそのセッションの解答一覧（`learning_logs`）を展開する。
  各行に単語・正誤・入力内容・所要時間を出す。

## 11. 集計の置き場所

- SQL で完結する集計（習熟度の語数、苦手単語の抽出、取り違えの候補ログ取得）は
  リポジトリのクエリで行う。すべて `profileId` を条件に含める（NFR-11）。
- 複数の結果を組み合わせる計算（欠損日の 0 埋め、正解率の算出、ストリーク、
  取り違えの組の突合、反応時間の平均）は `providers/stats_aggregates.dart` と
  `providers/reaction_time_stats.dart` の**純粋関数**にし、単体テストする。
  ウィジェットの `build` の中で計算しない。

## 12. テスト観点

- 学習が 0 件のとき、習熟度カードが `EmptyState` になる。
- 一度も測定していないとき、語彙力カードが `EmptyState` になる。
- スピードモード未実施のとき、反応の速さカードが存在しない。
- 取り違えの組が0件のとき、取り違えカードが存在しない。
- 欠損日が 0 埋めされ、30日分ちょうどのバーが描かれる。
- 解答 0 の日で正解率の折れ線が切れる（0% の点を打たない）。
- 反応時間の平均が「時間内に正解した問題」だけで計算される。
- 学習対象の単語帳を切り替えると習熟度内訳と苦手単語が変わり、
  ストリーク・学習量・語彙力・反応時間は変わらない。
- 学習者を切り替えるとすべてのカードが切り替わる。
- 苦手単語の条件（解答9回/10回、正解率59%/60%）の境界。
- 習熟度の語族単位で、全語がマスターの語族だけが「全部」に数えられる。
- 中断したセッションが履歴に残り「中断」バッジが付く。
- ストリークのカレンダーで 04:00 区切りが正しく反映される。
