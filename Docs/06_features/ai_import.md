# AI に作ってもらった単語帳の取り込み（AI Import）

対応要件: FR-105〜FR-112
実装: `domain/usecases/wordbook_json_codec.dart`, `data/seeds/prompt_assets.dart`,
`application/ai_import_service.dart`,
`ui/screens/paste_import_screen.dart`, `ui/screens/prompt_guide_screen.dart`,
`assets/prompts/*.txt`

姉妹アプリ breezy-recipe-stock の「貼り付け取込」（[../../breezy-recipe-stock/Docs/06_features/recipe_import.md]）
と同じ作法を、単語帳に合わせて置き換えたもの。

## 1. 狙い

同梱のプリセット単語帳は6冊で固定だが、必要な語彙は人によって違う。
「看護実習で使う英単語」「読んでいる洋書に出てくる語」のような**自分だけの単語帳**を、
生成AI に作ってもらって取り込めるようにする。

- アプリから生成AI を呼ばない（通信しない）。**利用者が自分の AI に貼り付けて、結果を持ち帰る**。
  NFR-04（TTS を除く全機能がネットワークなしで動作する）を崩さないため。
- 取り込みは既存の単語マスタと同じ規則に従う。同じ `(headword, partOfSpeech)` の語がすでにあれば
  **行を増やさず所属だけを足す**（学習状態を分けない。[wordbooks.md] §4）。

### 1.1 UI に IT 用語を出さない

画面の文言に「JSON」「インポート」「パース」を出さない。
利用者から見た操作は「**AI に単語帳を作ってもらう**」→「**貼り付けて取り込む**」の2つ。
本書と実装の中では JSON と呼ぶ。

## 2. 取込データ仕様（EncelloWordbook v1）

プロンプトに埋め込むスキーマ。**版フィールドを必須**にし、将来の拡張に備える。

```json
{
  "encelloWordbook": "1",
  "name": "看護実習の英単語",
  "emoji": "🩺",
  "note": "実習で出てくる基本語",
  "words": [
    {
      "headword": "patient",
      "partOfSpeech": "noun",
      "phonetic": "/ˈpeɪʃənt/",
      "meaning": "患者",
      "exampleEn": "The patient is resting in the next room.",
      "exampleJa": "その患者は隣の部屋で休んでいます。",
      "level": 2
    },
    {
      "headword": "take care of",
      "partOfSpeech": "phrase",
      "meaning": "〜の世話をする",
      "level": 2
    }
  ]
}
```

### 2.1 フィールド定義

| フィールド | 型 | 必須 | 検証規則 |
|---|---|---|---|
| `encelloWordbook` | string | ✔ | `"1"` のみ受理。他値は「新しい形式です。アプリを更新してください」 |
| `name` | string | ✔ | 1〜40文字 |
| `emoji` | string | — | 1文字。無ければ `📗` |
| `note` | string | — | 0〜200文字 |
| `words[]` | array | ✔ | 1件以上、**200件以下**（§4.1） |
| `words[].headword` | string | ✔ | 1〜60文字。英字・スペース・ハイフン・アポストロフィのみ |
| `words[].partOfSpeech` | string | ✔ | `PartOfSpeech` の値のいずれか |
| `words[].meaning` | string | ✔ | 1〜200文字 |
| `words[].phonetic` | string | — | 空文字は「値なし」として扱う |
| `words[].exampleEn` / `exampleJa` | string | — | 0〜200文字。**`exampleEn` があるなら `exampleJa` も必須**（片方だけを許すと詳細画面が中途半端になる） |
| `words[].level` | number | — | 1〜5。無ければ 1 |

- 発音記号と例文は**空を許容する**。全語に無理やり付けさせるより、空のまま取り込む方が正しい
  （[wordbooks.md] §2 と同じ方針）。
- `presetId` は受け取らない。取り込んだ語はユーザーの語であり、「元に戻す」の対象にしない。

### 2.2 前処理（`WordbookJsonCodec.preprocess`）

1. 先頭・末尾の空白と BOM を除去
2. コードフェンス（<code>```json</code> 〜 <code>```</code>）を除去
3. 最初の `{` から対応する最後の `}` までを抽出（AI の前置き・後置きの説明文を無視）
4. **全角引用符・全角コロンの半角化は行わない**。構文の推測修復はフォールバック禁止に触れる。
   パースに失敗したら §5 の「直してもらう文」を出して AI 側で直させる

### 2.3 重複の扱い

| 状況 | 挙動 |
|---|---|
| 取り込むファイル内で `(headword, partOfSpeech)` が重複 | エラー。「N行目と重複しています」 |
| 既存の共有語と一致 | **新しく作らず、その語を新しい単語帳へ所属させる**。学習状態は共有される |
| 既存の語と一致し、訳が違う | 既存の訳を**上書きしない**。プレビューに「すでにある語（訳はそのまま）」と表示する |

同じ語の訳を静かに書き換えると、他の単語帳での学習体験まで変わってしまう。
訳を変えたいときは単語詳細から明示的に編集させる。

## 3. 検証とプレビュー

### 3.1 全件を列挙する

最初の1件で打ち切らない。行番号と理由を並べて出す。

```
3語目「Patient!」: 英単語として扱えない文字が含まれます
7語目: 日本語訳がありません
12語目「run」: 品詞が不正です: verbs
18語目「apple」: 5語目と重複しています
```

### 3.2 プレビュー

取り込む前に、単語帳名と語数、先頭20語（見出し語・品詞・訳）を出す。
すでにある語には「すでにある語」のバッジを付け、**新しく増える語数**を明記する
（「38語のうち、新しく増えるのは 31語です」）。

### 3.3 部分取り込みの選択

弾いた行がある場合、**「正しい語だけ取り込む」か「やめる」**を選ばせる。
推測で補完して取り込むことはしない。

実装メモ（`WordbookJsonCodec.decode`）: 単語帳そのものが作れない致命的な問題
（版違い・`name` なし・`words` が配列でない・201件以上）のときだけ結果全体を
`null` にする。個々の語の問題（見出し語の文字種・品詞不正・訳なし等）は、
その語だけを弾いたうえで**残りの語だけを持つ単語帳**を返し、`issues` に理由を
全件添える。呼び出し側（SCR-24）はこの結果を見て「正しい語だけ取り込む」か
「やめる」を出す。1語も残らなかった場合は「取り込める語が1つもありませんでした」
を `issues` に足し、部分取り込みの選択肢自体を出さない（直してもらう文のみ）。

### 3.4 トランザクション

単語帳・単語・所属を1トランザクションで書く。途中で失敗したら1件も残さない。

## 4. プロンプト定型文

設定 > データの「**AI に単語帳を作ってもらう**」から `PromptGuideScreen`（SCR-25）を開く。
取り込み画面（SCR-24）からも同じ画面へ行ける。

文言は ARB ではなく `assets/prompts/` のテキストで持つ。スキーマを変えたら必ず同期する。

| ファイル | 用途 |
|---|---|
| `assets/prompts/ask_wordbook.txt` | ① 単語帳を作ってもらう（テーマ・語数・レベルを差し込む） |
| `assets/prompts/convert_to_wordbook.txt` | ② 直前のやりとりを取込用データに変換してもらう |
| `assets/prompts/ask_wordbook_for_import.txt` | ③ **統合**（①＋②を1回で。おすすめの導線） |
| `assets/prompts/fix_wordbook.txt` | ④ 取り込みに失敗したとき、AI に直してもらう（§5） |

画面の並びは番号順（①→②→③）にし、最後に共通の「アプリに貼り付ける」手順を置く。
テーマ・語数・レベルの入力欄は、差し込みが要る ① と ③ の**各カード内**に置く（②は不要）。

**①〜③のすべてにスキーマ定義を埋め込む。** ① を「語を挙げてもらうだけ」にすると、
その出力は取り込めず、必ず ② を続けて実行させることになる。②は「すでに AI と会話して
語を出してもらった後から合流する」ための導線であって、①の続きではない。
①③の違いはスキーマの有無ではなく、**選定の指示の細かさ**（③が本命の導線）にする。

### 4.1 語数の上限を指示に含める

1回の出力が長いと、AI の応答が途中で切れて JSON が壊れる。これが取り込み失敗のいちばん多い原因になる。

- プロンプトに「**1回につき最大50語**」を明記する。
- 200語の単語帳を作るときは、**同じ単語帳へ4回に分けて取り込む**導線を用意する
  （取り込み先に「新しく作る / 既存の単語帳に足す」を選ばせる）。
- スキーマ側の上限も 200件にして、それを超える入力は「一度に取り込める語数を超えています。
  50語ずつに分けて作ってもらってください」と示す。
- 「既存の単語帳に足す」で選べる単語帳は、プリセット単語帳とマイ単語帳を除いた
  共有のユーザー単語帳（`source != preset` かつ `category != myWords`）に絞る
  （[wordbooks.md] §4 の「削除できる単語帳」と同じ範囲）。プリセットは同梱内容を
  固定し、マイ単語帳は個人の語だけを持つ場所のため、AI 取り込みの共有語を
  混ぜる先にしない。

### 4.2 ③ 統合プロンプト（要旨）

> 英単語の単語帳を作って、次の仕様の JSON だけで出力してください。説明文は不要です。
> 【テーマ】{{theme}} 【語数】{{count}}語（最大50語） 【レベル】{{level}}
> 【単語の選び方】そのテーマで実際によく使われる語を選ぶ／同じ綴りで品詞が違う語は別の項目にする／
> 訳はその品詞で最もよく使う語義から最大3つを `；` 区切りで／例文はその語のレベルで読める語彙だけで10語以内／
> 例文を書いたら和訳も必ず付ける／発音記号（IPA・米音）は自信がある語だけに書き、無ければ省く
> （後にスキーマ定義と、そのまま取り込める出力例を同梱する）

- 「自信がある語だけ発音記号を書く」と明示するのは、無理に埋めさせると誤った IPA が混ざるため。
  空を許容する仕様（§2.1）とセットで意味を持つ。

### 4.3 プロンプトとスキーマがずれないようにする

`test/domain/prompt_templates_test.dart` が次を検証する。

- ①③のプロンプトに埋め込んだ**出力例が `WordbookJsonCodec` でそのまま取り込める**こと
- ①③がテーマ・語数・レベルのトークン（`{{theme}}` / `{{count}}` / `{{level}}`）を持つこと
- ①②③がスキーマの必須フィールド名をすべて含むこと
- ④がエラー一覧（`{{errors}}`）と元テキスト（`{{source}}`）のトークンを持つこと

スキーマを変えてプロンプトを直し忘れると、このテストが落ちる。

## 5. 失敗したときに前へ進める

取り込みに失敗した状態で利用者を放り出さない。

- パースに失敗した場合と検証に落ちた場合の**どちらでも**、
  「**AI に直してもらう文をコピー**」ボタンを出す。
- コピーされる文は `assets/prompts/fix_wordbook.txt` に、
  **エラーの一覧**と**元の貼り付けテキスト**を差し込んだもの。

> 次のデータをアプリに取り込もうとしたら、下のエラーが出ました。
> エラーを直した JSON だけを、もう一度出力してください。説明文は不要です。
> 【エラー】{{errors}}
> 【元のデータ】{{source}}

- 貼り付けたテキストは画面から消さない。直した結果で上書きできるようにする。

## 6. 生成できるもの / できないもの

| 対象 | 取り込み | 理由 |
|---|---|---|
| 単語帳（語のまとまり） | ○ | 本書の対象 |
| 語の部品（接頭辞・語根・接尾辞） | v2 以降 | 部品は語との紐付けが要り、AI の出力を検証する術が弱い（[word_parts.md]） |
| 擬似語（語彙力測定用） | × | 実在語でないことの保証が要る。AI の出力で担保できない（[vocab_size_test.md]） |
| 4択の誤答選択肢 | × | 誤答は既存語から実行時に選ぶ（[quiz_mode.md] §2）。データとして持たない |

「問題」を AI に作らせないのは、encello の出題がすべて**単語データから自動で組み立てられる**ため。
語さえ入れば8モードすべてが動く。問題文まで持ち込むと、モードを足すたびにデータが陳腐化する。

## 7. テスト観点

- `WordbookJsonCodec`: 正常系 / コードフェンス除去 / 前置き文の除去 / 各フィールドの境界値 /
  エラーの全件列挙 / 版の不一致 / 200件超え / ファイル内重複 / `exampleEn` だけがある行
- 実際の AI 出力例をフィクスチャ（`test/fixtures/ai_import/`）に貯めて回帰させる
- 既存語と同じ `(headword, partOfSpeech)` を含む取り込みで、`words` が増えず所属だけが増える
- 既存語の訳が上書きされない
- 取り込みの途中で失敗したら単語帳・単語・所属が1件も残らない
- 「直してもらう文」にエラー一覧と元テキストが両方入る
- §4.3 のプロンプト同期テスト
