# 語のつくり（Word Parts：接頭辞・語根・接尾辞）

対応要件: FR-71〜FR-75
実装: `data/database/tables/word_parts.dart`, `ui/widgets/word_parts_card.dart`,
`ui/screens/word_part_detail_screen.dart`, `ui/screens/parts_study_screen.dart`

## 1. 狙い

中学までは丸暗記で足りるが、高校以降は語彙が一気に増えて追いつかなくなる。
**語根1つが10語以上を連れてくる**ため、増加局面での効きが最も大きい。

```
port（運ぶ）→ import / export / transport / portable / support / report / porter
```

`port` の意味を知っていれば、初見の `deport` も「離れて運ぶ → 国外追放する」と見当がつく。
未知語に出会ったときに推測する力そのものを鍛える。

## 2. データ

### 2.1 `word_parts`（語の部品）

| 列 | 型 | 説明 |
|---|---|---|
| `id` | int | PK |
| `form` | text | 表記（`re-` / `port` / `-able`）。ハイフンの位置が種別を表す |
| `type` | text | `prefix` / `root` / `suffix` |
| `meaning` | text | 日本語の意味（`再び；元へ` / `運ぶ` / `〜できる`） |
| `origin` | text? | 由来（`ラテン語 portare`）。空を許す |
| `note` | text? | 補足（`-able は動詞に付いて形容詞を作る`） |
| `level` | int | 1〜5。何級あたりで役に立つか |

`UNIQUE(form, type)`。

### 2.2 `word_part_links`（単語との紐付け）

| 列 | 型 | 説明 |
|---|---|---|
| `wordId` | int | PK, FK |
| `partId` | int | PK, FK |
| `position` | int | 語の中での順番（0 から） |

`import` = `im-`(0) + `port`(1)、`portable` = `port`(0) + `-able`(1)。

- 紐付けは**任意**。すべての単語に付ける必要はない。
  紐付けの無い語では、語のつくりカードごと表示しない。
- 語源として無理のある分解はしない。
  たとえば `understand` を `under` + `stand` と分けても意味の説明にならないので、紐付けない。
  こじつけの分解は、推測の役に立たないどころか誤った推測を教える。

### 2.3 収録の目安

| 種別 | 個数 |
|---|---|
| 接頭辞 | 約50（`re-` `un-` `in-` `dis-` `pre-` `ex-` `com-` `sub-` `trans-` …） |
| 語根 | 約80（`port` `spect` `dict` `duc` `fer` `mit` `pos` `scrib` `tract` `vert` …） |
| 接尾辞 | 約30（`-able` `-tion` `-ment` `-ous` `-ify` `-ize` `-al` `-ist` …） |

段階投入できる。`level 1〜2`（中学〜高校基礎で効くもの）から入れ、
紐付いた語から順に表示が現れる。

## 3. 単語詳細での表示（FR-72）

単語詳細（SCR-09）の例文カードの下に「語のつくり」カードを置く。

```
語のつくり
  im-        port
  中へ    +  運ぶ        → 中へ運ぶ ＝ 輸入する

  同じ語根の単語（port：運ぶ）           7語 >
    export   transport   portable  …
```

- 部品を横に並べ、下に意味を添える。矢印の右は `word_parts_note`（後述）か、
  無ければ単語の `meaning` の先頭語義。
- 部品タップで語の部品の詳細（SCR-16）へ。
- 「同じ語根の単語」は最大6語をチップで並べ、全件は SCR-16 で見る。
- 紐付けが1つも無い語では、このカードを出さない。

### 3.1 分解の説明文

`word_part_links` だけでは「im- + port → 輸入する」の橋渡しが弱い語がある
（`report` = 「後ろへ運ぶ → 報告する」など、一段の説明が要る）。

`words` に `partsNote`（text?）を持たせ、必要な語にだけ1行の説明を書く。
空なら部品の意味を `+` で繋いだだけを表示する。**説明を機械生成しない**。

## 4. 語の部品の詳細（SCR-16）

| 内容 |
|---|
| 見出し: `port` ＋ 種別バッジ（語根） |
| 意味: 運ぶ |
| 由来: ラテン語 portare |
| 補足: `note` |
| この部品を含む単語の一覧（習熟度バッジ付き。行タップで単語詳細） |
| 「この部品の単語だけ学習する」ボタン |

一覧は現在のプロファイルの習熟度で並べ替えられる（未学習を上に）。
「`port` の仲間 12語のうち、5語を覚えている」というキャプションを添える。

## 5. 語のつくりモード（第5の学習モード・FR-74）

`mode = parts`。他のモードと同じ枠組み（キュー生成・SM-2・XP）に乗せる。

### 5.1 出題形式

問題ごとに2種類をランダムに出す。

| 形式 | 問い | 答え方 |
|---|---|---|
| 部品→意味 | `spect` の意味は？ | 4択（見る／運ぶ／書く／導く） |
| 意味→部品 | 「書く」を表す語根は？ | 4択（`scrib` / `dict` / `spect` / `duc`） |

- 誤答選択肢は**同じ種別（prefix / root / suffix）**から選ぶ。
  接頭辞の問題に語根を混ぜると、種別だけで答えが割れる。
- 正解の後に「この部品を含む単語」を3語まで示す。部品と実際の語を必ず結び付ける。

### 5.2 学習状態

語の部品は `words` ではないので、`word_reviews` には載せられない。
`part_reviews`（`profileId`, `partId`, `repetition`, `intervalDays`, `easeFactor`, `dueAt`, …）を
別に持ち、**同じ `Sm2Scheduler` を使う**。スケジューラは `ReviewState` しか見ない純粋関数なので、
そのまま再利用できる。

grade は4択と同じ扱い（正解 4 / 不正解 1。上限4）。

### 5.3 出題対象

**紐付いた単語が3語以上ある部品だけ**を出題する。
1語しか繋がっていない部品を覚えても応用が利かない。

## 6. 推測の練習（FR-75）

語のつくりモードの3問に1問、**未学習語の意味を推測させる**問題を混ぜる。

```
deport という単語の意味は？
  de-（離れて）+ port（運ぶ）  ← 部品の意味だけヒントに出す

  [ 国外追放する ]  [ 保管する ]  [ 依存する ]  [ 出発を遅らせる ]
```

- 対象は「その語の部品をすべて既習（`part_reviews` が定着以上）で、
  かつ語そのものは未学習」の語。
- 正解しても `word_reviews` は作らない。**推測できたことと覚えたことは別**。
  結果画面では「推測に成功 3/4」と別枠で見せる。
- 条件を満たす語が無い場合は、この形式を出さない（無理に作らない）。

## 7. データの出典

語源・語根の情報は既存の語源辞典の記述を写さず、
一般に知られた語源（ラテン語・ギリシア語の原形と意味）と、日本語の説明文を自分で書く。
語源の解釈が分かれる語は収録しない。

## 8. テスト観点

- 紐付けの無い単語の詳細に「語のつくり」カードが存在しない。
- `partsNote` が空のとき、部品の意味を `+` で繋いだ表示になる。
- 「同じ語根の単語」に自分自身が含まれない。
- 語のつくりモードの誤答選択肢がすべて同じ種別になる。
- 紐付いた語が2語の部品が出題されない（3語以上のみ）。
- `part_reviews` が `Sm2Scheduler` で正しく更新され、`word_reviews` に影響しない。
- 推測問題の対象が「部品すべて定着以上 かつ 語は未学習」に限られる。
- 推測問題に正解しても `word_reviews` の行が作られない。
- 条件を満たす語が無いとき推測問題が出ない。
