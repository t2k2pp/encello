# 継続の仕組み（Gamification）

対応要件: FR-40〜FR-43, FR-46
実装: `domain/usecases/xp_calculator.dart`, `domain/usecases/streak_calculator.dart`,
`application/achievement_evaluator.dart`

## 1. デイリー目標

- 単位は**問題数**（語数ではない）。同じ語を2回解けば2問と数える。
- 選択肢 10 / 20 / 30 / 50 / 100、既定 20（FR-40）。
- その日に適用されていた目標値は `daily_stats.goalCount` に保存する。
  後から目標を変えても、過去の達成判定は動かない。
- `answeredCount >= goalCount` になった瞬間に `goalMet = true` を立て、以後 false に戻さない。
- フラッシュカードで自己評価しなかったカードは数えない（[flashcard_mode.md] §3）。

## 2. ストリーク

`StreakCalculator` は `daily_stats` の `(studyDate, goalMet)` のリストから計算する純粋関数。

| 値 | 定義 |
|---|---|
| 現在のストリーク | 今日（未達なら昨日）から遡って `goalMet = true` が連続する日数 |
| 最長ストリーク | 全期間での最大連続日数 |

- 学習日は 04:00 区切り（[03_data_model.md] §4）。
- **今日がまだ未達でもストリークは切れていない**。昨日まで連続していれば、その値を表示し続ける。
  日付が変わって「昨日も未達」になった時点で 0 になる。
- 救済（フリーズ・チケット）は用意しない。切れたら切れたと示す。
- ストリークが 0 のときは炎を描かず、「今日から始めましょう」と表示する
  （灰色の炎で「失っている」ことを強調しない）。

## 3. XP

`XpCalculator.forAnswer()` は純粋関数。1問ごとに算出し、`daily_stats.xp` と
`study_sessions.xpEarned` に加算する。

| 要素 | 値 |
|---|---|
| 正解の基本点 | 10 |
| モード係数 | spell / listening / family ×1.5、speed ×1.2、choice / parts / confusion ×1.0、flashcard「覚えた」×0.8 |
| ヒント減点 | 開示した1文字につき −3（下限 0） |
| 惜しい | 3（不正解だが 0 にはしない） |
| 不正解 | 0 |
| 時間切れ（speed） | 0 |
| セッション内の連続正解ボーナス | 5問連続ごとに +10 |
| デイリー目標の達成ボーナス | その日1回だけ +50 |
| スピード全問時間内ボーナス | 50問すべて時間内正解で +50 |

- モード係数はスペル系（綴りを産出するもの）を高くする。綴りを書けることがこのアプリの到達点なので、
  4択を回すだけでレベルが上がらないようにする。語形変化もスペル入力なので同じ係数にする。
- レベルは累計 XP から算出する。`level = floor(sqrt(totalXp / 100)) + 1`
  （1→2 に 100XP、9→10 に 1,900XP。序盤は速く、後半は緩やかになる）。
- 累計 XP は `daily_stats.xp` の総和として求める。別テーブルに持たない。

## 4. 実績

`AchievementEvaluator` が、セッション終了時と日付切り替え時に未解除の条件を判定する。
`achievements` テーブルには解除済みだけを残し、条件そのものはコードに置く。

| code | 名称 | 条件 |
|---|---|---|
| `first_session` | はじめの一歩 | 初めてセッションを完了した |
| `streak_3` / `streak_7` / `streak_30` / `streak_100` | 継続 3/7/30/100日 | ストリークが到達した |
| `learned_100` / `learned_500` / `learned_1000` | 100/500/1000語に触れた | `word_reviews` の行数 |
| `mastered_10` / `mastered_100` / `mastered_500` | 10/100/500語マスター | `masteryLevel = 3` の語数 |
| `perfect_20` | 全問正解 | 20問以上のセッションを正解率100%で終えた |
| `spell_500` | 綴り職人 | spell モードの正解が通算500問 |
| `night_owl` / `early_bird` | 夜更かし / 早起き | 学習日の 00:00〜04:00 / 04:00〜07:00 に解いた |
| `all_modes` | 全モード制覇 | 8つのモードすべてでセッションを完了した |
| `parts_50` | 語源使い | 語の部品を50個マスターした |
| `family_100` | 語形自在 | 語形変化クイズに100問正解した |
| `confusion_10` | 見分けの達人 | 取り違えの組を10件解消した |
| `speed_1s` | 瞬間反応 | スピードモードで平均1.0秒を切った |
| `vocab_3000` | 語彙3000 | 語彙力測定で推定3,000語に到達した |

- 解除は結果画面でカード1枚として示す（全画面の演出は挟まない）。
  同時に複数解除した場合は縦に並べる。
- 未解除の実績も SCR-14 で条件と進捗（`7 / 30日`）を見せる。隠さない。
- 実績の追加でコードを増やしても、既存の `achievements` 行には影響しない。

## 5. 数え方の一貫性

目標・ストリーク・XP・実績はすべて**現在の学習者**のもの。学習者をまたいで合算しない。

その学習者の中では、「触れた語数」「マスター語数」は**選択中の単語帳に限定しない**。
学習対象を切り替えるたびに実績の進捗が上下すると、達成の意味が失われるため、
その人が触れた全単語を対象に数える。

一方、ホームの「今日の復習 N語」と統計の習熟度内訳は**選択中の単語帳に限定する**。
こちらは「いま何を勉強するか」の指標なので、対象を絞るのが正しい。
この違いは統計画面のキャプションに1行で示す。

学習者どうしの比較（ランキング・並べ方）は v1 では出さない。
兄弟でレベルが違うときに、比較が続ける気を削ぐ方に働くため。

## 6. テスト観点

- `goalCount` を後から変えても過去日の `goalMet` が変わらない。
- 今日が未達でも、昨日まで連続していればストリークが維持される。
- 日付が変わって昨日も未達になった時点でストリークが 0 になる。
- 03:59 の学習が前日に、04:01 の学習が当日に計上される。
- XP: ヒント3文字使用時の下限が 0 になる。連続正解が5問ごとに +10 される。
  デイリー達成ボーナスが1日1回だけ付く。
- レベル計算の境界（99/100 XP、1899/1900 XP）。
- 実績が二重に解除されない。同時解除が両方記録される。
