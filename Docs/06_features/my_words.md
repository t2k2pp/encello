# マイ単語（My Words）

対応要件: FR-92〜FR-97
実装: `ui/screens/my_words_screen.dart`, `ui/dialogs/quick_add_word_sheet.dart`,
`application/shared_text_receiver.dart`

## 1. 狙い

教科書・問題集・洋書・動画で**自分が実際に出会った語**は、単語帳から与えられた語より圧倒的に覚えやすい。
出会った文脈がそのまま記憶の手がかりになるため。

社会人になってからも、仕事で出会った語を入れ続けられる。
プリセット単語帳を使い切った後もアプリが役に立ち続けるための機能でもある。

## 2. 所有と可視範囲

- `words` に `ownerProfileId`（int?, FK, index）を足す。
  null = 共有（プリセット・インポート）、非 null = そのプロファイルのマイ単語。
- 辞書一覧に出るのは **共有の語 ＋ 自分のマイ単語**。他人のマイ単語は出さない。
- 各プロファイルに「マイ単語」単語帳を1冊自動で持たせる
  （`source = user`、`presetId = null`、削除不可）。プロファイル作成時に一緒に作る。

同じ `(headword, partOfSpeech)` を兄と弟が別々に登録した場合、**2行になる**。
共有マスタの一意制約は `ownerProfileId` を含めた
`UNIQUE(headword, partOfSpeech, ownerProfileId)` にする。
片方のメモや訳をもう片方に見せないため、ここは重複を許す。

## 3. 未整備状態（下書き）を許す

出会った瞬間に訳や例文まで書かせると、登録そのものが面倒になって続かない。
**見出し語だけで登録できる**ようにする。

- `words` に `isDraft`（bool, default false）を足す。
- `isDraft = true` の語は `meaning` が空でよい（リポジトリで検証を分岐する）。
- 下書きの語は**出題されない**。キュー生成のプールから外す。
  訳の無い語を出しても答え合わせができない。
- 辞書一覧で `accentSoft` の「下書き」バッジを付け、フィルタ「下書きのみ」で絞り込める。
- ホームに下書きが3語以上たまったら「下書きの単語が5語あります。訳を書きましょう」のカードを出す。

### 3.1 訳は自分で書く

自動翻訳・辞書引きの API は使わない。

- 通信を伴うため、オフラインで完結するという前提が崩れる。
- そして何より、**自分の言葉で訳を書くこと自体が学習になる**。
  辞書の語義をそのまま貼るより、文脈に合う訳を自分で選んだ方が定着する。

出会った文を書き残せるよう、`exampleEn` に「出会った文」をそのまま入れることを勧める
（入力欄のヒントを「この単語を見つけた文」にする）。

## 4. クイック登録

### 4.1 アプリ内から

辞書画面のヘッダー `＋単語` と、シェル FAB の長押しから開く。

```
単語を追加                                (sectionTitle)
  [ apple                    ]           ← アプリ内英字キーボードで入力
  品詞  [ 名詞 ▾ ]                        （未定 も選べる）
  訳    [                    ]           ← 空でよい（下書きになる）
  見つけた文 [                ]           ← 任意
  [ 保存 ]   [ 保存してもう1語 ]
```

- 見出し語の入力にも**アプリ内英字キーボード**を使う。ここだけ OS の IME を出すと
  配列が変わって使いにくく、予測変換で綴りを確認できてしまう。
- 「保存してもう1語」でシートを閉じずに連続登録できる。授業中に何語も出てくる場面向け。
- 共有の語と同じ `(headword, partOfSpeech)` がすでにある場合は、新規作成せずに
  「この語は『中学英単語』にあります」と示し、**マイ単語に登録するか、既存の語を学習対象にするか**を選ばせる。

### 4.2 他アプリからの共有

OS の共有シートでテキストを受け取る（`receive_sharing_intent`）。
ブラウザや電子書籍で単語を選択 →「共有」→ encello を選ぶ、で登録シートが開く。

| 受け取ったテキスト | 挙動 |
|---|---|
| 1語（英字のみ） | 見出し語に入れてシートを開く |
| 複数語の文 | 文を「見つけた文」に入れ、**文中の語をチップで並べて選ばせる** |
| 日本語を含む | 「見つけた文」にだけ入れ、見出し語は空でシートを開く |

- 推測で見出し語を決めない。複数語のときは必ず選ばせる。
- プロファイルが2人以上のときは、シートの先頭に「だれのマイ単語にしますか」を出す。
  共有からの起動ではプロファイルゲートを通っていないため。

## 5. マイ単語画面（SCR-17）

設定 > マスタ、または辞書のフィルタ「マイ単語」から入る。
[STYLE_GUIDE §3] の一覧の型。フィルタは「習熟度」「下書きのみ」。

- 行タップで単語詳細（共有の語と同じ画面。編集・削除ができる）。
- 一括操作: 選択して「まとめて学習対象にする」「まとめて削除」。
- 下書きの語だけを順に埋めていく「訳を書く」モードを置く。
  見出し語と見つけた文を出し、訳の入力欄だけを並べて次々に埋められるようにする。

## 6. 学習への組み込み

- マイ単語帳を学習対象に選べば、通常のキュー生成に混ざる（[srs_scheduler.md] §6）。
- 下書きは除外される。
- マイ単語は掲載順ではなく**登録が新しい順**に新規出題する。
  出会った直後に復習するのが最も効く。

## 7. エクスポート

- JSON エクスポートにマイ単語を含める。`ownerProfileId` はプロファイル名で書き出し、
  インポート時に名前で解決する（id は端末間で一致しないため）。
  同名のプロファイルが無ければ、インポート時に作る。
- CSV エクスポートはマイ単語帳も対象にする。

## 8. テスト観点

- 兄のマイ単語が弟の辞書一覧に出ない。
- 同じ `(headword, partOfSpeech)` を2人が登録すると2行になる。
- `isDraft = true` かつ `meaning` が空で保存できる。
- 下書きの語がキュー生成に含まれない。
- 訳を入力すると `isDraft` が false になり、出題対象に入る。
- 共有テキストが1語のとき見出し語に入り、文のときは語の選択になる。
- 日本語を含むテキストで見出し語が空のままになる（推測しない）。
- 共有の語と同じ見出し語＋品詞を登録しようとすると、既存を示す分岐に入る。
- マイ単語の新規出題順が登録の新しい順になる。
- エクスポート → 別端末インポートでマイ単語が正しいプロファイルに入る。
