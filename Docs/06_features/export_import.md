# エクスポート / インポート

対応要件: FR-51〜FR-53, FR-56, FR-57
実装: `data/services/export_import_service.dart`, `ui/screens/settings_screen.dart`（データタブ）

## 1. エクスポート

| 形式 | 内容 | 用途 |
|---|---|---|
| JSON（全体） | 単語帳・単語・所属・学習状態・履歴・日次集計・実績 | 機種変更、バックアップ |
| CSV（単語帳単位） | 単語の7列のみ（学習状態を含まない） | 他アプリ・表計算での編集 |

- JSON の構造は [03_data_model.md] §7。`formatVersion: 1`。
- ファイル名: `encello_backup_YYYYMMDD_HHmm.json` / `encello_<単語帳名>_YYYYMMDD.csv`。
- 書き出しは `file_selector` で保存先を選ばせ、`share_plus` で共有もできるようにする。
- 単語数が多い場合でも UI をブロックしないよう、JSON の組み立てとエンコードは
  `compute`（別 isolate）で行う。Drift の読み出しはルート isolate で先に済ませ、
  プレーンな Dart のリストを isolate へ渡す。

## 2. インポート

### 2.1 モード

| モード | 挙動 |
|---|---|
| 追加（既定） | 既存データを消さずに取り込む。衝突は §2.2 の規則で解決する |
| 置換 | 既存の全データを削除してから取り込む。**二段確認**を要する |

置換の二段確認: `confirmDestructive` で「すべての学習記録が消えます」を確認した後、
もう一度「本当に置き換える」を確認する（[STYLE_GUIDE §4.3]）。

### 2.2 「追加」での衝突解決

単語の同一性は `(headword, partOfSpeech)` で判定する（数値 id は端末間で一致しないため）。

| 対象 | 規則 |
|---|---|
| 単語帳 | `presetId` が一致すれば同じ単語帳。無ければ名前が一致するものを同じとみなす。どちらも無ければ新規作成 |
| 単語 | 既存があれば**上書きしない**（手元の編集を優先）。無ければ新規作成 |
| 所属 | 和集合を取る |
| 学習状態 | `lastReviewedAt` が新しい方を採用する。片方が null なら非 null を採用 |
| 履歴（logs） | `sessionId` が既存に無いセッションの分だけ取り込む |
| 日次集計 | 同じ `studyDate` があれば `answeredCount` などを**合算**し、`goalMet` は OR を取る |
| 実績 | 和集合を取る。`unlockedAt` は古い方を残す |

- 学習状態を「新しい方」で解決するのは、2台の端末で並行して学習した場合に
  進んでいる方を残すため。合算はしない（SM-2 のパラメータは足し算に意味がない）。
- 日次集計だけは合算する。こちらは純粋な回数の記録であり、足し合わせて正しい。

### 2.3 検証と失敗の扱い

取り込み前に全体を検証し、**1件でも致命的な問題があれば何も取り込まない**。

| 検証 | 失敗時の表示 |
|---|---|
| JSON として解析できる | 「ファイルを読み取れません」 |
| `formatVersion` がサポート範囲内 | 「このバックアップは新しいバージョンで作られています（v2）。アプリを更新してください」 |
| 必須キーが揃っている | 「バックアップの形式が不正です: words が見つかりません」 |
| 単語の必須項目（headword / partOfSpeech / meaning）が揃っている | 「N件の単語に不足があります」＋先頭10件を一覧表示 |

- 部分的に取り込んで「たぶん大丈夫」にしない。
- 取り込み全体を1トランザクションで行い、途中で失敗したら巻き戻す。
- 成功したら SnackBar で件数を報告する（「単語1,842件・学習記録912件を取り込みました」）。

### 2.4 プレビュー

取り込む前に内容を示す。

```
バックアップの内容
  作成日時    2026-08-01 21:30
  アプリ版    1.0.0
  単語帳      6冊
  単語        3,812件（うち新規 120件）
  学習記録    912件（うち新しい 43件）
  実績        7件
[ 追加で取り込む ]   [ 置き換える ]
```

## 3. CSV インポート

単語帳単位の CSV 取り込みは [wordbooks.md] §5 に定める。

## 4. サンプルデータ（FR-56）

- 設定 > データの「サンプルデータ」カードに、投入 / 削除の `OutlinedButton` を**横並び2列**で置く
  （[STYLE_GUIDE §5.1]）。
- 内容: 30語の単語帳1冊と、直近14日分の学習履歴・日次集計。
  統計とストリークの見え方をすぐ確認できる分量にする。
- サンプル由来の単語帳は `source = preset`、`presetId = sample_v1` で区別する。
  削除では `presetId` が `sample_v1` の単語帳と、そこにしか属さない単語・学習状態・履歴を消す。
- 投入済みなら投入ボタンを無効化する。削除は `confirmDestructive` を挟み、
  `foregroundColor: accentDeep`。
- 実データが参照している単語（他の単語帳にも属している語）は残し、件数を報告する。

## 5. 学習状態のリセット（FR-57）

- 設定 > データの「学習状態をリセット」。`word_reviews` / `learning_logs` /
  `study_sessions` / `daily_stats` / `achievements` を削除し、`words` と `wordbooks` は残す。
- **二段確認**を要する。1段目で消える対象を列挙し、2段目で確定する。
- 実行前に「先にバックアップを書き出す」導線を同じダイアログに置く。

## 6. テスト観点

- JSON のラウンドトリップ: エクスポート → 空 DB へインポートで、全テーブルの件数と値が一致する。
- 「追加」で既存の単語が上書きされない。
- 学習状態が `lastReviewedAt` の新しい方で解決される（両方向で検証）。
- 日次集計が同じ日付で合算され、`goalMet` が OR になる。
- `formatVersion: 2` のファイルが拒否される。
- 単語の必須項目が欠けたファイルで、1件も取り込まれない。
- 取り込み中に例外が起きたら全部巻き戻る。
- サンプル削除で、他の単語帳にも属する語が残る。
- 学習状態リセット後に `words` の件数が変わらない。
