## 1. エクスポート

| 形式 | 内容 | 用途 |
|---|---|---|
| JSON（全体） | 学習者・単語帳・単語・所属・語の部品・語族・学習状態・履歴・日次集計・実績・語彙力測定・解消した取り違え・マイ単語 | 機種変更、バックアップ |
| CSV（単語帳単位） | 単語の7列のみ（学習状態を含まない） | 他アプリ・表計算での編集 |

- JSON の構造は [03_data_model.md] §10。`formatVersion: 1`。
- **音声パックは含めない**。数十MB〜数百MBになり、バックアップの用途に合わない。
  音声パックは元の ZIP を保管して取り込み直す。エクスポート時にその旨を1行示す
  （「音声パックは含まれません。ZIP を別に保管してください」）。
- ファイル名: `encello_backup_YYYYMMDD_HHmm.json` / `encello_<単語帳名>_YYYYMMDD.csv`。
- 書き出しの作法は**プラットフォームで分ける**。`file_selector` の保存ダイアログ
  （`getSaveLocation`）はデスクトップだけの機能で、Android / iOS には実装が無い。
  - デスクトップ: 保存ダイアログで場所を選ばせてそこへ書く
  - Android / iOS: アプリのデータ領域へ書いてから**共有シート**（`share_plus`）に渡し、
    保存先はシート側で選んでもらう
  例外を握って別の方法へ落とす書き方はしない（分岐を明示する）。
- 単語数が多い場合でも UI をブロックしないよう、JSON のエンコードは
  `compute`（別 isolate）で行う。Drift の読み出しはルート isolate で先に済ませ
  （`collectBackup`）、プレーンな `Map` を isolate へ渡す（`encodeBackupJson`）。
  isolate を起こすのは `backupEncoderProvider` の役目にし、ウィジェットテストでは
  その場で変換する実装に差し替える（[07_testing_strategy.md] §4）。
- **マイ単語帳（`category = myWords`）は単語帳の一覧に書き出さない**。持ち主に紐づく
  ため、取り込み側は学習者を作るときに1冊作り、その人のマイ単語をそこへ所属させる。

## 2. インポート

### 2.1 モード

| モード | 挙動 |
|---|---|
| 追加（既定） | 既存データを消さずに取り込む。衝突は §2.2 の規則で解決する |
| 置換 | 既存の全データを削除してから取り込む。**二段確認**を要する |

置換の二段確認: `confirmDestructive` で「すべての学習記録が消えます」を確認した後、
もう一度「本当に置き換える」を確認する（[STYLE_GUIDE §4.3]）。

### 2.2 「追加」での衝突解決

数値 id は端末間で一致しないため、すべて自然キーで解決する。

| 対象 | 同一性のキー |
|---|---|
| 学習者 | `name` |
| 単語帳 | `presetId`。無ければ `name` |
| 単語（共有） | `(headword, partOfSpeech)` |
| 単語（マイ単語） | `(headword, partOfSpeech, 学習者名)` |
| 語の部品 | `(form, type)` |
| 語族 | `baseForm` |

| 対象 | 規則 |
|---|---|
| 学習者 | 同名があれば同じ人とみなす。無ければ作る。設定は既存を優先し、上書きしない |
| 単語帳 | 一致すれば同じ単語帳。無ければ新規作成 |
| 単語 | 既存があれば**上書きしない**（手元の編集を優先）。無ければ新規作成 |
| 所属 | 和集合を取る |
| 語の部品・語族・紐付け | 和集合を取る。既存の意味・説明は上書きしない |
| 学習状態（`word_reviews` / `part_reviews`） | `lastReviewedAt` が新しい方を採用する。片方が null なら非 null を採用 |
| 履歴（logs） | `sessionId` が既存に無いセッションの分だけ取り込む |
| 日次集計 | 同じ `(学習者, studyDate)` があれば `answeredCount` などを**合算**し、`goalMet` は OR を取る |
| 実績 | 和集合を取る。`unlockedAt` は古い方を残す |
| 語彙力測定 | `takenAt` が既存に無い分だけ取り込む |
| 解消した取り違え | 和集合を取る。`resolvedAt` は古い方を残す |

- 学習状態を「新しい方」で解決するのは、2台の端末で並行して学習した場合に
  進んでいる方を残すため。合算はしない（SM-2 のパラメータは足し算に意味がない）。
- 日次集計だけは合算する。こちらは純粋な回数の記録であり、足し合わせて正しい。

### 2.3 検証と失敗の扱い

取り込み前に全体を検証し、**1件でも致命的な問題があれば何も取り込まない**。

| 検証 | 失敗時の表示 |
|---|---|
| JSON として解析できる | 「ファイルを読み取れません」 |
| `formatVersion` がサポート範囲内 | 「このバックアップは新しいバージョンで作られています（v2）。アプリを更新してください」 |
| 必須キーが揃っている | 「バックアップの形式が不正です: words が見つかりません」 |
| 単語の必須項目（headword / partOfSpeech / meaning）が揃っている | 「N件の単語に不足があります」＋先頭10件を一覧表示 |

- 部分的に取り込んで「たぶん大丈夫」にしない。
- 取り込み全体を1トランザクションで行い、途中で失敗したら巻き戻す。
- 成功したら SnackBar で件数を報告する（「単語1,842件・学習記録912件を取り込みました」）。

### 2.4 プレビュー

取り込む前に内容を示す。

  アプリ版    1.0.0

## 4. サンプルデータ（FR-56）

- 設定 > データの「サンプルデータ」カードに、投入 / 削除の `OutlinedButton` を**横並び2列**で置く
  （[STYLE_GUIDE §5.1]）。
- 内容: 30語の単語帳1冊と、直近14日分の学習履歴・日次集計。
  統計とストリークの見え方をすぐ確認できる分量にする。
- サンプル由来の単語帳は `source = preset`、`presetId = sample_v1` で区別する。
  削除では `presetId` が `sample_v1` の単語帳と、そこにしか属さない単語・学習状態・履歴を消す。
- 投入済みなら投入ボタンを無効化する。削除は `confirmDestructive` を挟み、
  `foregroundColor: accentDeep`。
- 実データが参照している単語（他の単語帳にも属している語）は残し、件数を報告する。

## 5. 学習状態のリセット（FR-57）

- 設定 > データの「学習状態をリセット」。**現在の学習者の分だけ**を消す。
  `word_reviews` / `part_reviews` / `learning_logs` / `study_sessions` / `daily_stats` /
  `achievements` / `vocab_size_tests` / `resolved_confusions` を削除し、
  `words` / `wordbooks` / マイ単語は残す。
- 他の学習者の記録には触れない。ダイアログのタイトルに学習者名を入れる
  （「たろうさんの学習状態をリセット」）。
- **二段確認**を要する。1段目で消える対象と件数を列挙し、2段目で確定する。
- 実行前に「先にバックアップを書き出す」導線を同じダイアログに置く。

## 5.1 未所属の単語の整理

どの単語帳にも属さなくなった単語（単語帳を削除した後に残った語）を、
設定 > データの「未所属の単語を整理」で手動削除する（[wordbooks.md] §4）。
自動では消さない。学習状態が付いている語は件数を示して確認する。

この整理は**端末全体**が対象で、学習者ごとではない（単語は全員で共有するため）。
未所属の語に誰かのマイ単語が含まれる場合は、その件数と
「ほかの学習者の語も消える」ことを確認の文面に出す。

## 5.2 使われていない音声ファイルの整理

`word_audios` に対応する行が無い音声ファイルを、
設定 > データの「使われていない音声ファイルを整理」で手動削除する。
起動時に自動で走らせない（[pronunciation.md] §3.3）。解放される容量を事前に示す。

## 6. テスト観点

- JSON のラウンドトリップ: エクスポート → 空 DB へインポートで、全テーブルの件数と値が一致する
  （2人の学習者・マイ単語・語の部品・語族・語彙力測定を含む）。
- 「追加」で既存の単語・語の部品の意味が上書きされない。
- 同名の学習者があれば新規作成されず、既存の設定が上書きされない。
- 同名の学習者が無ければ作られ、その人の記録が正しく紐付く。
- マイ単語が正しい学習者に入る。
- 学習状態が `lastReviewedAt` の新しい方で解決される（両方向で検証）。
- 日次集計が同じ `(学習者, 日付)` で合算され、`goalMet` が OR になる。
- `formatVersion: 2` のファイルが拒否される。
- 単語の必須項目が欠けたファイルで、1件も取り込まれない。
- 取り込み中に例外が起きたら全部巻き戻る。
- エクスポートに音声パックのバイナリが含まれない。
- サンプル削除で、他の単語帳にも属する語が残る。
- 学習状態リセットで、**他の学習者の記録が消えない**。
- 学習状態リセット後に `words` とマイ単語の件数が変わらない。
