# 00. 概要（Overview）

## 目的

英単語を **「綴る・聴く・見分ける」** の3方向から反復し、忘却曲線に沿って再出題することで
**中学〜大学受験・英検・TOEIC の語彙を定着させる**学習アプリを、売り物レベルの品質で新規開発する。

単語帳アプリの主戦場は「めくって眺める」だが、encello は **綴りを自分で書けること**を到達点に置く。
そのため、答えが予測変換で出てしまう OS のキーボードを一切使わず、**アプリ内の英字キーボード**で入力させる。

## アプリ名

**encello（エンチェロ）**。姉妹アプリ（pricello / breezy-recipe-stock / stocello / pacello / shcello / mdcello）の
7つ目にあたり、UI 規約は [../../Docs/STYLE_GUIDE.md] を正本とする。既定のテーマ配色は**ピンク**。

## スコープ

### v1 で作るもの

| 区分 | 内容 |
|---|---|
| 学習モード | ① スペル（和訳→英綴り）② リスニング・スペル（発音→英綴り）③ フラッシュカード（3種の自動送り）④ 4択クイズ ⑤ スピード（制限時間つき・反応時間を測る）⑥ 語のつくり（接頭辞・語根・接尾辞）⑦ 語形変化（派生語）⑧ 取り違えドリル |
| 入力 | アプリ内英字キーボード（QWERTY / ABC 配列切替）。OS の IME を出さない |
| 出題順 | SM-2 ベースの間隔反復（期限到来の復習を優先し、新規語で充足） |
| 学習者 | 1台に複数人を登録。単語は共有し、学習の記録・設定は人ごとに分ける |
| 語彙力測定 | Yes/No 方式＋擬似語補正で推定語彙数を出し、次に取り組む単語帳を提案する |
| 辞書 | 英→日 / 日→英 の検索、単語詳細（発音記号・品詞・訳・例文・語のつくり・語族）、英日両方の読み上げ |
| 単語帳 | 中学 / 高校 / 英検 / TOEIC のプリセットを同梱。ユーザー追加・CSV/JSON インポート。**生成AI に作ってもらった単語帳の貼り付け取込**（[06_features/ai_import.md]） |
| マイ単語 | 出会った語をその場で登録。見出し語だけの下書きを許す。他アプリからの共有にも対応 |
| 継続の仕組み | デイリー目標・連続学習日数（ストリーク）・XP・実績バッジ・学習リマインダー |
| 統計 | 習熟度の内訳、直近の学習量推移、苦手単語、取り違えの組、反応時間、語彙力の推移 |
| データ | JSON/CSV のエクスポート・インポート（学習履歴を含む） |
| 音声 | 端末の TTS（英語・日本語）。速度・ピッチ・音声の選択 |

### v1 で作らないもの（Non-Goals）

| 項目 | 理由 / 予定 |
|---|---|
| 物語（Cloze）モード | 文脈学習は狙いとして残すが、本文コンテンツの整備が本体と同規模になる。→ v2（[09_roadmap.md]） |
| クラウド同期 / アカウント | 端末内完結を前提とする。複数端末はエクスポート/インポートで移す |
| 発音の採点（音声認識） | 端末内で無料・高精度に成立しないため扱わない |
| 広告 / 課金 | 後から足せる構造にとどめる |
| Web / デスクトップの正式サポート | TTS とキーボード体験がモバイル前提。ビルドは通るが対象外 |

## 対象プラットフォーム

- **Android**（スマートフォン / タブレット）
- **iPhone / iPad**（iOS / iPadOS）
- 想定端末: 2023年以降に発売された端末。

## 対象ユーザー

- 中学生〜高校生（学校の語彙を確実に綴れるようにしたい）
- 大学受験・英検・TOEIC で語彙を増やす必要がある人
- 仕事で出会った語を貯めていく社会人

**レベルの違う人が同じアプリを長く使える**ことを前提に設計する。
英検4級の学習者と3級を終えた学習者では、必要な単語帳も1日の量も違う。
起動時の語彙力測定でレベルを判定し、その人に合った単語帳を提案する（[06_features/vocab_size_test.md]）。
1台の端末を家族で共有する場合は、学習者を分けて記録する（[06_features/profiles.md]）。

同じ単語（例 `apple`）が中学単語帳と英検単語帳の両方に載っている場合、
**学習状態は（学習者ごとに）単語1つにつき1つ**にまとめる。
中学単語帳で覚えた語は、英検単語帳を開いても既習として扱われる（[03_data_model.md] §2.3）。

## 語彙を増やす速度を上げるための設計

暗記と復習だけでは、覚える速度は語数に比例したままになる。
encello は次の3つで**1語あたりの学習が連れてくる語数**を増やす。

| 仕掛け | 効き方 |
|---|---|
| 語のつくり（接頭辞・語根・接尾辞） | `port`（運ぶ）を1つ覚えると import / export / transport / portable / support が繋がる。初見の語を推測する力そのものを鍛える |
| 派生語ファミリー | decide / decision / decisive / decidedly を1つの語族として扱う。語形変化そのものが入試・英検で直接問われる |
| 取り違えドリル | その人が実際に混同している組を解答履歴から割り出し、2語を並べて区別させる。既製の「紛らわしい語リスト」より自分の誤りの方が効く |

加えて、**正確さと速さを別に鍛える**。SM-2 は「正しく思い出せる」を作るが、
読解に必要な「見た瞬間に意味が出る」は別の能力なので、スピードモードで反応時間を測って伸ばす
（[06_features/speed_mode.md]）。

## 用語

| 用語 | 定義 |
|---|---|
| 学習者 (Profile) | 1台の端末を使う人。学習の記録と設定を持つ。単語は学習者間で共有する |
| 単語 (Word) | 学習の最小単位。見出し語＋品詞（＋持ち主）で一意。訳・例文・発音記号を持つ |
| 単語帳 (Wordbook) | 単語の集合（例: 中学英単語、英検2級）。単語と多対多 |
| マイ単語 (My Word) | 学習者が自分で登録した単語。持ち主にだけ見える |
| 下書き (Draft) | 見出し語だけ登録され、訳がまだ無い単語。出題されない |
| 学習状態 (Review) | ある学習者のある単語の間隔反復パラメータ（次回出題日・容易度・連続正解数） |
| 出題 (Item) | 1回の問い。単語＋モード＋出題方向（EN→JA / JA→EN）で決まる |
| セッション (Session) | 学習の1まとまり（既定20問）。開始から終了までの記録を残す |
| モード (Mode) | spell / listening / flashcard / choice / speed / parts / family / confusion の8種 |
| 習熟度 (Mastery) | 未学習 / 学習中 / 定着 / マスター の4段階。学習状態から導出する |
| 語の部品 (Word Part) | 接頭辞・語根・接尾辞。単語に紐付き、部品自身も学習状態を持つ |
| 語族 (Word Family) | 派生関係にある語のまとまり（decide / decision / decisive / decidedly） |
| 取り違えの組 (Confusion Pair) | その学習者が繰り返し混同している2語。解答履歴から検出する |
| 語彙力測定 (Vocabulary Size Test) | Yes/No 方式＋擬似語補正で推定語彙数と級帯到達率を出す測定 |
| デイリー目標 (Daily Goal) | 1日に解く問題数の目標（既定20）。達成でストリークが伸びる |
| ストリーク (Streak) | 目標を達成した連続日数 |

## 設計上の原則

- **綴れることを正解の定義にする**。1文字違いは「惜しい」と表示するが正解にはしない
  （綴り学習アプリで綴り誤りを正解にすると目的が壊れる。[06_features/spell_mode.md] §4）。
- **曖昧な状態を握りつぶさない**。TTS の音声が端末に無い場合は「読み上げできません」と示し、
  無音で成功したように振る舞わない（[06_features/tts.md] §4）。
- **純粋ロジックを分離する**。SM-2 の計算、出題キューの生成、綴り判定、XP 計算は
  Flutter にも Drift にも依存しない関数として `domain/` に置き、単体テストで固める。
- **デザインの一貫性**。画面は [../../Docs/STYLE_GUIDE.md] の型（一覧画面・設定5タブ・共通部品）で構築する。
