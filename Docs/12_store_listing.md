# 12. ストア掲載文・ペルソナ（Store Listing）

ストア登録（Google Play / App Store）に使う紹介文の原稿と、その土台となるペルソナ・
ユーザーストーリー。文字数制限は [11_release_quickref](11_release_quickref.md) A-11 / I-9 参照。

v1 は**広告なし・課金なし**（[00_overview](00_overview.md) の Non-Goals）。
「無料で全部使える」を隠さずに前に出す。

## 1. ペルソナとユーザーストーリー

紹介文・スクリーンショットの訴求順は、このペルソナの優先順（P1→P3）に合わせる。

### P1: 佐藤 陽向（14）— 単語テストで綴りが書けない中学2年生

- 英語の授業についていけてはいるが、単語テストで綴りを落とす。単語帳アプリは
  4択で「見たことある」までは行くのに、いざ書くと出てこない。
- **ストーリー**: 中学2年生として、テストで綴りを**書けるように**なりたい。
  選択肢から選べるだけでは点にならないから。
- **利用の流れ**: 中学英単語の単語帳を選ぶ → スペルモードで20問 →
  間違えた語はその場でもう一度出る → 翌日、復習として自動で出てくる。
- **効く仕掛け**: OS のキーボードを使わないので**予測変換で答えが出ない**。
  1文字違いは「惜しい」と示され、どこが違うかが差分でわかる。

### P2: 山本 詩織（17）— 英検2級を受ける高校2年生

- 英検準2級は取った。2級の語彙が足りない自覚があるが、市販の単語帳は
  どこから手を付ければいいか分からず、最初の100語で止まっている。
- **ストーリー**: 英検2級を受ける高校生として、**いまの自分の語彙に合った単語帳**から
  始めたい。背伸びした本を買っても続かないから。
- **利用の流れ**: 起動直後の語彙力測定（18問）で推定語彙数が出る →
  レベルに合う単語帳が提案される → 毎日20問の目標をストリークで続ける。
- **効く仕掛け**: 語のつくり（接頭辞・語根・接尾辞）と語形変化で、
  1語覚えると周辺の語がまとめて入る。

### P3: 川村 篤（41）— 仕事で出会った語を貯めたい社会人

- TOEIC の点は要るが、机に向かう時間は取れない。英文メールや記事で知らない語に
  出会っても、その場でメモしないと忘れる。
- **ストーリー**: 忙しい社会人として、**出会った語をその場で1タップで貯めて**、
  訳は後からまとめて書きたい。腰を据えて調べる時間はないから。
- **利用の流れ**: ブラウザから語を共有 → 見出し語だけの下書きができる →
  通勤中に「訳を書く」でまとめて埋める → 自分の語だけの単語帳として復習に回る。
- **効く仕掛け**: 生成AI に単語帳を作ってもらう定型文をコピーでき、
  返ってきた内容をそのまま貼り付けて取り込める。

### 家族で使う場合

1台の端末に学習者を複数登録でき、学習記録も設定も人ごとに分かれる。
兄弟で1台のタブレットを使う家庭を想定した機能なので、掲載文にも1行入れる。

## 2. Google Play 掲載文（原稿）

### タイトル（30字以内）

```
encello - 書いて覚える英単語アプリ
```

代替案: `encello エンチェロ｜英単語を綴って覚える` / `encello - 英単語を書いて覚える`

### 短い説明（80字以内）

```
選ぶだけでは書けるようになりません。専用キーボードで綴りを打って覚える英単語アプリ。中学・高校・英検・TOEICの6冊を収録。広告なし・登録不要・通信なし。
```

文字数（2026-08 時点で実測）: タイトル 22/30・短い説明 78/80・
名前 13/30・サブタイトル 12/30・キーワード 60/100・プロモーション 107/170。
**改稿したら数え直すこと**（全角も1字と数える）。

### 詳細説明（4000字以内・原稿）

```
「見たことはあるのに、書けない」を終わらせる英単語アプリです。

4択で選べる単語は、いざテストで書こうとすると出てきません。encello（エンチェロ）は、綴りを自分の手で打つことを学習の中心に置いた単語アプリです。

■ 予測変換が出ないから、本当に覚えられる
・アプリ内の英字キーボードで綴りを入力します。スマホのキーボードは開きません
・だから予測変換や履歴で答えが見えてしまうことがありません
・1文字違いは「惜しい」と表示し、どこが違うのかを並べて見せます
・キーボードは QWERTY と ABC 配列を切り替えられます

■ 8つの学習モード
・スペル: 和訳を見て英語を綴る（このアプリの中心）
・リスニング・スペル: 発音を聞いて綴る
・フラッシュカード: 手を使わず流して浴びる（無音／英語読み上げ／日本語読み上げ）
・4択クイズ: すきま時間に
・スピード: 制限時間つき。反応の速さを測る
・語のつくり: 接頭辞・語根・接尾辞から意味を推測する
・語形変化: decide → decision のような派生語をまとめて
・取り違えドリル: あなたが実際に混同した組だけを出す

■ 忘れる前に、もう一度出てくる
・間隔反復（SM-2）で、覚えた語は間隔を広げ、あやしい語は早く戻します
・間違えた語はセッション中にもう一度出ます
・単語帳をまたいで学習状態はひとつ。中学英単語で覚えた語は、英検の単語帳でも既習として扱われます

■ 自分のレベルから始められる
・18問の語彙力測定で、いまの推定語彙数がわかります
・結果に合わせて、次に取り組む単語帳を提案します
・測定は何度でも。語彙が増えていく様子が統計に残ります

■ 6冊を収録（合計6,900語以上）
・中学英単語 / 高校英単語 基礎 / 高校英単語 応用 / 英検準2級 / 英検2級 / TOEIC 基本語
・訳・例文・発音記号つき。例文はその語のレベルで読める語彙だけで書いています

■ 自分の単語も貯まっていく
・出会った語はその場で登録。訳は後からでも大丈夫（下書きとして残ります）
・他のアプリから共有した語もそのまま取り込めます
・生成AIに単語帳を作ってもらうための文をコピーでき、返ってきた内容を貼り付けて取り込めます
・CSV での取り込み・書き出しにも対応

■ 家族で1台でも
・学習者を複数登録できます。学習記録も1日の目標も、人ごとに分かれます
・単語帳は共有するので、二重に持つ必要はありません

■ 続けるための仕掛け
・1日の目標、連続学習日数、XP、実績バッジ
・学習リマインダー（通知を許可したときだけ）
・習熟度の内訳、苦手な語、取り違えの組、反応の速さを統計で

■ データはあなたの端末の中だけ
・アカウント登録は不要です
・アプリはインターネット通信を一切行いません（Android版はネットワーク権限すら持ちません）
・広告も、アクセス解析もありません
・記録はJSONで書き出せて、いつでも持ち出せます

■ こんな方に
・単語テストで綴りを落としてしまう中高生の方
・英検・大学入試・TOEICに向けて語彙を増やしたい方
・4択のアプリでは手ごたえがないと感じている方
・お子さんと1台の端末を分けて使いたいご家庭
```

> 「必ず覚えられる」「点数が上がる」のような**効果の断定はしない**（§5）。

## 4. スクリーンショット構成案（両ストア共通・6〜8枚）

ペルソナの優先順に合わせ、1枚目は P1 の価値（綴りを打って覚える）を最初に見せる。

| # | 画面 | キャプション案 |
|---|---|---|
| 1 | スペル学習（入力中・アプリ内キーボード） | 「スマホのキーボードは開きません」 |
| 2 | スペル学習（「惜しい」の差分表示） | 「どこが違うか、その場でわかる」 |
| 3 | モード選択シート（8モード） | 「綴る・聴く・見分ける、8つの練習」 |
| 4 | 語彙力測定の結果＋推奨単語帳 | 「いまの語彙に合う1冊から始める」 |
| 5 | 単語詳細（語のつくり・語族カードあり） | 「1語覚えると、周りの語もついてくる」 |
| 6 | ホーム（ストリーク・今日の目標） | 「毎日つづく仕掛け」 |
| 7 | 学習者の切り替え | 「1台を、家族で分けて」 |
| 8 | 設定 > 情報 / データ | 「データは端末の中だけ。いつでも持ち出せる」 |

撮影時の注意:

- **サンプルデータを入れた状態で撮らない**。実際に少し学習した状態を作る
  （空のグラフや `0` が並んだ画面をストアに出さない）。
- 学習者名は実在の個人名を避け、`ひなた` `しおり` のような一般的な名前にする。
- iPad 用は 13" が必須（[11_release_quickref](11_release_quickref.md) I-10）。
  `CenteredContent` が効いて間延びしないことを見せる。

## 5. 文言のトーン規約

- 「必ず覚えられる」「点数が上がる」等の**効果の断定はしない**（審査・景表法の両面で安全側）。
- 他社アプリの名指し比較はしない。「4択だけでは書けるようにならない」という
  **一般論の指摘**にとどめる。
- プライバシー訴求は「**データは端末の中だけ**」を定型句として全媒体で統一する。
  「通信しない」は事実なので言い切ってよい（[10_oss_licenses](10_oss_licenses.md) §5）。
- 収録語数は**延べ6,927語**が正しい（見出し語の実数はこれより少ない）。
  掲載文では「合計6,900語以上」と丸めて書き、盛らない。
- 生成AI 連携は「AI が単語帳を作ってくれる」ではなく
  「**AI に頼む文をコピーでき、返ってきた内容を取り込める**」と書く。
  アプリ自身が AI を内蔵していると誤解されるとリジェクト要因になる。
- iOS の共有受信は Xcode 側の対応が済むまで掲載文に書かない
  （[11_release_quickref](11_release_quickref.md) I-3）。
  Android 先行で出す場合は、Play 側だけ「他のアプリから共有」を残す。
